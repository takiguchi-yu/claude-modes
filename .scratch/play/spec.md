# clawd-wander: ひとり遊び（波乗り・小踊り・蝶々）

本体の Clawd がひとりで歩いている間、ときどき「ひとり遊び」を 1 つ始める。遊びは 2 種類で、始めるときにランダムに 1 つ選ぶ。

- 波乗り（.scratch/surf/spec.md）
- 蝶々を追いかける（.scratch/butterfly/spec.md）

2026-10-08 に小踊り（.scratch/dance/spec.md）を取り下げた（ユーザーの希望）。

**Status:** done（2026-10-08。テストで確認。小踊り・蝶々は、遊びを 1 つに絞って確率を上げた写しでvhs の録画で確認）
**Blocked by:** なし

## 要件

1 コマ = 100 ms。「ひとり」「歩ける」「奥行き」は .scratch/surf/spec.md と同じ。

```text
R1  [WHEN]  ひとり遊びの設定（R5）がオンで、ひとりで、歩ける本体が、行列もひとり遊びもしていないコマに、始められる遊び（R2）が 1 つ以上あれば、
            帯は PLAY_CHANCE（1/600。平均でおよそ 1 分に 1 回）の確率で、始められる遊びから 1 つを同じ確率で選んで始める。
R2  [IF]    遊びごとの始められる条件: 波乗りは広いほうの奥行きが MIN_RIDE（30 ピクセル）以上、蝶々は MIN_CHASE（60 ピクセル）以上。
R3  [WHILE] ひとり遊びの間、帯は別のひとり遊びも行列も始めない。
R4  [WHEN]  ひとり遊びの間に本体が歩けなくなった（驚いた・居眠りした・押しつぶされた）、または引っ込められたとき、帯はその場で遊びをやめる。
            仲間が加わったときのやめ方は遊びごとに決める（波乗りは波が引く、蝶々は飛んでいく）。
R5  [WHERE] userConfig の play が false の場合、帯はひとり遊びを始めない（既定はオン。/config で変えられる）。
R6  [WHEN]  ひとり遊びが終わったとき、帯は本体を 5〜15 コマ立ち止まらせてから、また自分で歩かせる。
```

2026-10-08 にまとめた。それまでは波乗りだけで、設定は surf（波乗りのオン・オフ）だった。遊びを増やすときに、
遊びどうしが同時に始まらず、頻度（平均 1 分に 1 回）を保てるように、始めるところを 1 つにした。
設定 surf は play に名前を変えた（ユーザーの設定ファイルに surf の値が保存されていないことを確かめた）。

## 契約

```text
契約: Play（play.ts。Member.play の型。2026-10-08 に Member.surf から変えた）
- 値: null | { kind: 'surf' } & Surf | { kind: 'butterfly' } & Butterfly（2026-10-08 に dance を除いた）
- 不変: 本体だけが持つ。仲間は常に null

契約: playable(x, room)（play.ts）
- 事後: 始められる遊び（R2）の種類の一覧。順番は surf・butterfly

契約: startPlay(crew, random, canvas, timing = DEFAULT_TIMING)（crew.ts。2026-10-08 に paddleOut から変えた）
- 事後: T7 なら、本体が始められる遊びのうち random で選んだ 1 つを始める（beginPlay と同じ）。それ以外は crew そのもの
- 不変: crew を変更しない。T2〜T5 では random を呼ばない。T6 では 1 回、T7 では 2 回呼ぶ（始めるか・どれにするか）

契約: beginPlay(crew, kind, canvas, random)（crew.ts）
- 事前: kind は始められる遊び
- 事後: 本体が kind の遊びを始めた顔ぶれ（遊びごとの始め方は各仕様）
```

## テストとの対応

- [x] R1・R2・T2〜T7・契約 startPlay・playable: 条件がそろえば始め、始められる遊びから乱数で選ぶ。T2〜T5 では乱数を使わない
- [x] R3: ひとり遊びの間は行列もほかの遊びも始めない
- [x] R4: 歩けなくなる・引っ込められると、どの遊びもその場でやめる
- [x] R5・T1・register: play が false なら 10 分ひとりで歩いても遊ばない。オン（既定）なら 10 分の間に遊ぶ
- [x] R6: どの遊びも、終わると立ち止まってから歩き出す
