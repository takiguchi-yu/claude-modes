# clawd-wander: テストが通ったら紙吹雪

テストを走らせる Bash（フラスコを持つ呼び出し）が成功したら、呼び出し元の 1 体の周りに紙吹雪を降らせる。
失敗したときの「!」（.scratch/emotes/spec.md の R3）と対になる。

**Status:** done（2026-10-08。テストで確認。vhs の録画で、テストが通ると紙片が降ることを確認）
**Blocked by:** なし

## 要件

1 コマ = 100 ms。「テストを走らせる Bash」は .scratch/props/spec.md の R20 の判定に当たる Bash。
「成功」は、呼び出しが拒否されず（deny なし）、エラーも返さない（isError でない）こと。

```text
R1  [WHEN]  テストを走らせる Bash の呼び出しが成功したとき、帯は呼び出し元の 1 体に CHEER_FRAMES（15 コマ = 1.5 秒）紙吹雪を降らせる。
            すでに降っていれば、残りを CHEER_FRAMES に戻す。
R2  [WHILE] 紙吹雪の間、帯はその 1 体の真ん中を中心に 4 ピクセルおきに並べた 8 枚の紙片（5 色: 赤・黄・緑・青・桃）を、
            少しずつずらした時刻から、上から下へ 3 コマに 1 マス（2 ピクセル）ずつ落とす。紙片は 1 マス（2×2 ピクセル）をちょうど埋める四角で、
            マスの区切りにそろえて置く（1 マスに 2 色しか出せないので、紙片がマスをまたぐと隣の色に塗られて消えるため）。
            帯の下端を過ぎた紙片は消える。2026-10-08 に「1 ピクセルの紙片 6 枚」から変更（録画で、まばらで紙吹雪に見えず、
            本体と同じマスに入った紙片が本体の色に塗られて頭のこぶに見えたため）。
R3  [KEEP]  テストを走らせない Bash・失敗したテストの Bash では、紙吹雪を降らせない（失敗は引き続き「!」）。
R4  [WHILE] 現れかけ・消えかけの間、帯は紙吹雪を描かない（残りは減り続ける）。
R5  [KEEP]  紙吹雪の間も、帯はその 1 体の歩き方・道具・記号を変えない。
```

## 契約

```text
契約: celebrate(crew, id)（crew.ts）
- 事後: id の 1 体が消えきっていなければ、その 1 体の cheer が CHEER_FRAMES になる。それ以外は変わらない
- 不変: crew を変更しない。id がいなければ同じ顔ぶれを返す

契約: confettiPixels(left, width, x)（cheer.ts）
- 事前: left は残りコマ（1〜CHEER_FRAMES）、width は持ち主の絵の幅、x は持ち主の左端の帯でのピクセル位置
- 事後: 持ち主の左端を 0 とした紙片のピクセル（dx, y, color）。紙片はどれも 2×2 で、x + dx と y が偶数の位置から始まる（マスの区切りにそろう）。
        同じマスに 2 枚の紙片は入らない。y は 0〜5
- 不変: 同じ引数なら同じ結果（毎コマ同じ順番で落ちる）

契約: Actor.confetti（sprite.ts）
- 値: undefined | { left: number }
- 事後: confettiPixels の色で、持ち主の塗りとして描く
```

## テストとの対応

- [x] R1・契約 celebrate: 成功したテストの Bash で呼び出し元に CHEER_FRAMES が入り、降っている間なら戻る。いない id・消えきった 1 体では何もしない
- [x] R2・契約 confettiPixels: 8 枚・5 色・2×2 でマスの区切りにそろい、同じマスに 2 枚入らず、3 コマで 1 マス落ち、下端で消える
- [x] R3・register: テストでない Bash・失敗したテストでは降らない。成功したテストでは帯に紙吹雪の色が出る
- [x] R4: 出入りの途中は描かない
- [x] R5: 紙吹雪の間も道具を持ったまま歩く
