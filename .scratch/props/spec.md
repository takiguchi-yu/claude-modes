# clawd-wander: 道具を持つ

マスコットが、いま使っているツールに合わせて道具を持って歩く。編集中はハンマー、調べ物中は虫めがね、新しく書くときは鉛筆、仲間を呼ぶときは旗、待ちを始めるときは砂時計、テストを走らせるときはフラスコ（2026-10-07 に鉛筆・旗・砂時計・フラスコを追加）。

2026-10-08 に R23（持ち替えてから 1.5 秒は見せ続ける）を追加し、使い終えてから持つ時間を /config で変えられるようにした（.scratch/config/spec.md）。R23 は vhs の録画で確認（Read とテストの Bash を並べて呼ぶと、虫めがねが 1.40 秒見えてからフラスコに替わった。帯の色をコマごとに数えた）。

## 要件

1 コマ = 100 ms。「呼び出し元」は本体（`agentId` の無い `tool.call`）か、その `agentId` の仲間。
「使っている呼び出しの数」は、帯が 1 体ごとに数える数（始まりで 1 増やし、終わりで 1 減らし、消えきると 0 に戻す）。

```text
R1  [WHEN]   編集系ツール（Edit・MultiEdit・NotebookEdit。2026-10-07 に Write を R19 の鉛筆へ移した）の呼び出しが始まるとき、帯は呼び出し元の 1 体にハンマーを持たせ、その 1 体が使っている呼び出しの数を 1 増やす。2026-10-07 に「始まる・終わるときに残りを 30 コマ（3 秒）にする」から変更（終わってから次の呼び出しまでの間隔は中央値 9.6 秒で、3 秒以内に次が来るのは 1% しかなく、すぐ消えて見えたため。終わるときは R11）。
R2  [WHEN]   調べる系ツール（Read・Grep・Glob・WebSearch・WebFetch）の呼び出しが始まるとき、帯は呼び出し元の 1 体に虫めがねを持たせ、使っている呼び出しの数を 1 増やす。2026-10-07 に R1 と同じく変更（WebFetch は中央値 5.1 秒かかり、3 秒では使っている途中で消えたため）。
R3  [WHEN]   道具の対応表（下）に無いツールの呼び出しが始まる・終わるとき、帯は持っている道具も、使っている呼び出しの数も、残りコマも変えない。
R4  [WHEN]   使っている呼び出しが無く、道具の残りが尽きたとき、帯はその 1 体の道具をしまう。
R5  [WHILE]  道具を見せている間、帯は道具を向いている側（左向きなら左、それ以外は右）に、絵の端から 1 ピクセル空けて描く。左に描くときは道具の絵を左右反転する。
R6  [WHILE]  ハンマーを見せている間に歩いているとき、帯はハンマーを脚のコマに合わせて 1 ピクセル上下させる。
R7  [WHILE]  道具を持っている間も、帯はその 1 体の歩き方を変えない（行列では、前の 1 体との間に道具の分を空け、道具のぶん下がるときは後ずさりする。.scratch/parade/spec.md の R4・R10）。
R8  [IF]     驚いている・居眠りしている場合、または出入りの途中（現れかけ・跳ねる・消えかけ）の場合、帯は道具を描かない（使っている呼び出しの数と残りコマは R4・R11・R12 のとおりに変わり続ける）。2026-10-07 に居眠りを追加（使っている間は残りを減らさないので、60 秒を超える呼び出しの間に居眠りしうるため）。2026-10-08 から、呼び出しが動いている間は居眠りしない（.scratch/emotes/spec.md の R11）ので、使用中に居眠りで道具が消えることは無くなった。余韻の間の居眠りは残る。
R9  [KEEP][WHEN] ツールの呼び出しが始まる・終わるとき、帯は引き続き呼び出し元の居眠りを起こし、失敗なら驚かせる（.scratch/emotes/spec.md）。
R10 [KEEP][WHEN] 顔ぶれにいない id のツールが呼ばれたとき、帯は引き続き誰にも何もしない。
R11 [WHEN]   道具の対応表のツールの呼び出しが終わるとき（成功・失敗・拒否のどれでも）、帯は呼び出し元の 1 体にそのツールの道具を持たせ、使っている呼び出しの数を 1 減らし（0 より下げない）、残りを 100 コマ（10 秒）にする。2026-10-08 に、残りのコマ数を /config の prop_seconds で変えられるようにした（既定 10 秒。.scratch/config/spec.md）。
R12 [WHILE]  使っている呼び出しの数が 1 以上の間、帯はその 1 体の道具の残りを減らさない。
R13 [IF]     道具の対応表のツールの呼び出しが結果を返さずに抜けた（例外）場合、帯は R11 と同じく、使っている呼び出しの数を 1 減らして残りを 100 コマにする。
R14 [WHEN]   1 体が消えきったとき（消えかけが尽きたときと、現れかけたばかりで引っ込められてその場で消えきったときのどちらも）、帯はその 1 体の道具をしまい、使っている呼び出しの数を 0 にする。
R15 [WHEN]   消えきっている 1 体のツールの呼び出しが始まる・終わるとき、帯はその 1 体に道具を持たせない。
R16 [WHEN]   道具の対応表のツールの呼び出しが中断されたとき（フックの `next.signal` が abort したとき）、帯はその時点で R11 と同じく使い終えたとみなす。そのあと結果が届いても、1 つの呼び出しで 2 回は減らさない。
R17 [WHEN]   Agent（仲間を呼ぶ）の呼び出しが始まるとき、帯は呼び出し元の 1 体に旗を持たせ、使っている呼び出しの数を 1 増やす。
R18 [WHEN]   Monitor・ScheduleWakeup（待ちを始める）の呼び出しが始まるとき、帯は呼び出し元の 1 体に砂時計を持たせ、使っている呼び出しの数を 1 増やす。
R19 [WHEN]   Write（新しく書く）の呼び出しが始まるとき、帯は呼び出し元の 1 体に鉛筆を持たせ、使っている呼び出しの数を 1 増やす。
R22 [WHILE]  旗・フラスコ・鉛筆・砂時計を見せている間、帯はそれぞれの道具の色で塗ったドット絵（旗：灰色の竿と赤い布、フラスコ：灰色のガラスと緑の液体、鉛筆：ピンクの消しゴム・黄色の軸・削った木・黒い芯、砂時計：茶色の枠と黄色の砂）を描く。1 マスがちょうど 2 色で空きが無ければ、多いほうを文字の色、少ないほうを背景の色にする。ハンマー（黒鉄の頭と明るい木の柄）と虫めがね（銀の縁・中は空き・木の柄）も道具の色で描く（2026-10-07 にユーザーの希望で色付きにした。それまでは持ち主の色）。2026-10-07 に追加（1 色のドット絵では旗が「曲がった棒」、フラスコが「スコップ」に見え、記号 1 文字では小さすぎたため。ユーザーが色付きの見本から旗 A・フラスコ B・鉛筆 A・砂時計 A を選んだ）。
R21 [IF]     向いている側に道具を描くと帯からはみ出し、反対側なら収まる場合、帯は道具を反対側に、その側に持つ向きの絵で描く。どちらにも収まらなければ、向いている側に描いてはみ出す分を切る。2026-10-07 に追加（帯の左端で左を向いた本体のフラスコが切れて、縦の棒しか見えなかったため）。
R23 [WHILE]  ある道具に持ち替えてから 15 コマ（1.5 秒）たつまでの間に、別の道具の呼び出しが始まる・終わるとき、帯は今の道具を見せ続け、15 コマたった時点で最後に求められた道具に持ち替える。その間に今と同じ道具が求められたら、持ち替えを取りやめる。持ち替える前に道具をしまう（R4・R14）なら、持ち替えない。使っている呼び出しの数と残りコマは、持ち替えを待つ間も R1〜R20 のとおりに変わる。2026-10-08 に追加（Read のすぐあとにテストの Bash が始まると、虫めがねが数十ミリ秒でフラスコに替わり、見えなかったため。参考にしたのは clawd-dance の「ポーズは最低 1.5 秒見せる」）。
R20 [WHEN]   Bash の呼び出しのうち、コマンドがテストを走らせるもの（下の判定）が始まるとき、帯は呼び出し元の 1 体にフラスコを持たせ、使っている呼び出しの数を 1 増やす。テストを走らせない Bash は対応表に無いツールと同じに扱う（R3）。
```

道具の対応表（2026-10-07 に R17〜R20 を追加）:

| ツール | 道具 | 要件 |
| --- | --- | --- |
| Edit・MultiEdit・NotebookEdit | ハンマー | R1 |
| Read・Grep・Glob・WebSearch・WebFetch | 虫めがね | R2 |
| Agent | 旗 | R17 |
| Monitor・ScheduleWakeup | 砂時計 | R18 |
| Write | 鉛筆 | R19 |
| Bash（テストを走らせるコマンド） | フラスコ | R20 |

テストを走らせるコマンドの判定（R20）: heredoc（`<<'EOF'` から終わりの印まで。始まりの行の残りは残す。ヒアストリング `<<<` は heredoc ではない）の本文と、引用符（`'…'`・`"…"`）で囲まれた中身を除いてから、コマンドを `&&`・`||`・`;`・`|`・`&`・括弧・改行で区切り、区切ったどれかの語が次のどちらかに当たればテストとみなす。語は空白で区切り、区切りの先頭のシェルの言葉（`if`・`elif`・`while`・`until`・`!`・`then`・`do`・`else`）は飛ばして 1 語目を決める。引用符の外の `\x` は 1 文字として読み飛ばす。引用符の中で走らせるテスト（`bash -c "npm test"`）は見逃す。

- テストを実行するコマンドの名前（`pytest`・`jest`・`vitest`・`mocha`・`rspec`・`phpunit`・`unittest`・`tox`・`nextest`。2026-10-08 に `tox`・`nextest` を追加）を、どの位置にでも含む（`npx vitest run`・`python -m pytest`）。パスやバージョンが付いていてもよい（`vendor/bin/phpunit`・`./node_modules/.bin/jest`・`npx jest@29`）
- 2 語目以降に、ちょうど `test` という語か、`test:` で始まる語か、`--test`（`node --test`。2026-10-08 に追加）を含む（`npm test`・`go test ./...`・`cargo test`・`claude plugin test`・`make test`・`npm run test:unit`・`pnpm test:e2e`）。1 語目の `test` はシェルの条件判定なので数えない（`if test -f a`・`! test -f a` も、先頭の言葉を飛ばすので 1 語目になる）
- ただし、文字列・ファイル・ブランチの名前を扱うだけのコマンド（`grep`・`rg`・`echo`・`printf`・`cat`・`ls`・`find`・`sed`・`awk`・`head`・`tail`・`mkdir`・`rmdir`・`cd`・`pushd`・`rm`・`mv`・`cp`・`touch`・`ln`・`git`。2026-10-08 に `mkdir` 以降を追加）で始まる区切りは数えない（`grep -r test src`・`mkdir test`・`git checkout test` などを外すため）。1 語目を決めるとき、先頭の環境変数の設定（`CI=1`・`LC_ALL=C`）は飛ばす（2026-10-08 に追加）
- また、2 語目以降に道具を入れる・外す言葉（`install`・`i`・`add`・`uninstall`・`remove`・`upgrade`・`require`）を含む区切りも数えない（`pip install pytest`・`npm i -D vitest`・`cargo install cargo-nextest` を外すため。2026-10-08 に追加）

道具を持つと活動の途切れは 0 に戻る（R9）。呼び出しが動いている間は居眠りしない（.scratch/emotes/spec.md の R11。2026-10-08 から。それまでは 60 秒を超えて使うと道具を持ったまま居眠りし、道具を描かなかった）。

呼び出しの終わりが届かない場合でも、中断されれば（R16）、またはその 1 体が消えきれば（R14）、道具をしまう。終わりも中断も届かないまま、その 1 体が残っている間（仲間が動いていて本体が消えない間など）は、持ち続けうる。

使っている呼び出しの数は、実際に動いている呼び出しの数より少なくなることがある。数えずに始まった呼び出し（顔ぶれにいない間の R10、消えきっている間の R15）や、数えたあとで 0 に戻された呼び出し（R14）の終わりが、そのあとに始まった別の呼び出しの分を減らすため。そのときは、動いている呼び出しが残っていても、余韻が尽きると道具をしまう（次の始まり・終わりでまた持つ）。どれも、呼び出しが顔ぶれへの出入り（仲間が上限の 8 体を超えている間、作業していない間、消えきりをまたぐ間）と重なる場合だけで、まれ。

## 状態遷移表（1 体の道具）

「使用中」は使っている呼び出しが 1 つ以上ある状態、「余韻」は使っている呼び出しが無く残りが 1 以上ある状態。
始まる・終わるでは、道具をそのツールのもの（道具の対応表。R1・R2・R17〜R20）に持ち替える。対応表に無いツールはイベントにならない（R3）。
消えきっている 1 体には、始まる・終わるは届かないものとして扱う（R15）。中断（R16）は、終わると同じに扱う（1 つの呼び出しで 1 回だけ）。

| 現在 \ イベント | 始まる（R1・R2・R17〜R20） | 終わる（R11・R13・R16） | 1 コマ進む（R4・R12） | 消えきる（R14） |
| --- | --- | --- | --- | --- |
| なし | S1 → 使用中（数 1） | S2 → 余韻（残り 100） | S3 → なし | S4 → なし |
| 使用中（数 n） | S5 → 使用中（数 n + 1） | S6 → n = 1 なら余韻（残り 100）、n ≥ 2 なら使用中（数 n − 1） | S7 → 使用中（数 n のまま） | S8 → なし |
| 余韻（残り k） | S9 → 使用中（数 1） | S10 → 余韻（残り 100） | S11 → k = 1 ならなし、k ≥ 2 なら余韻（残り k − 1） | S12 → なし |

## 状態遷移表（見せる道具。R23）

上の表は「使っているか・いつしまうか」、この表は「どの道具を見せるか」。同じ 1 体の道具に、両方が同時に効く。
「経過」は今の道具に持ち替えてからのコマ数（15 で止める）。「求める」は、始まる・終わるで道具の対応表の道具が求められること。
道具をしまったら（上の表で「なし」になったら）、この表もなくなる。

| 現在 \ イベント | 今と同じ道具を求める | 別の道具を求める | 1 コマ進む |
| --- | --- | --- | --- |
| 確定（経過 < 15） | S13 → 確定（経過そのまま） | S14 → 持ち替え待ち（待つ道具 = 求めた道具） | S15 → 確定（経過 + 1） |
| 確定（経過 = 15） | S13 → 確定（経過そのまま） | S16 → 確定（求めた道具に持ち替え、経過 0） | S15 → 確定（経過 15 のまま） |
| 持ち替え待ち（経過 < 15） | S17 → 確定（待ちを取りやめ） | S14 → 持ち替え待ち（待つ道具を求めた道具に替える） | S18 → 経過 + 1 が 15 なら確定（待つ道具に持ち替え、経過 0）、そうでなければ持ち替え待ち（経過 + 1） |

道具を持っていないときに求めると、確定（求めた道具、経過 0）で持つ（S1・S2）。

## 契約

```text
契約: wield(crew, id, tool, command?, timing = DEFAULT_TIMING)  … 呼び出しが始まった（2026-10-07 に変更。同日 command を追加。2026-10-08 に timing を追加）
- 事前: tool はツール名
- 事後: propFor(tool, command) が道具を返し、id の 1 体が消えきっていなければ、その 1 体の道具が grab(道具, timing.propFrames) のとおりに変わり（見せる道具は R23）、途切れが 0 に戻る。それ以外は変わらない
- 不変: crew を変更しない。propFor(tool, command) が null なら crew そのものを返す。id がいなければ同じ顔ぶれを返す（R10）

契約: release(crew, id, tool, command?, timing = DEFAULT_TIMING)  … 呼び出しが終わった（2026-10-07 に新設。同日 command を追加。2026-10-08 に timing を追加）
- 事前: tool はツール名
- 事後: propFor(tool, command) が道具を返し、id の 1 体が消えきっていなければ、その 1 体の道具が relax(道具, timing.propFrames) のとおりに変わり（見せる道具は R23）、途切れが 0 に戻る。それ以外は変わらない
- 不変: wield と同じ

契約: Grip（Member.prop の型。2026-10-07 に { kind, left } から変更。2026-10-08 に held・next を追加）
- 値: null | { kind: PropId; using: number; left: number; held: number; next: PropId | null }
- kind は見せている道具、next は持ち替えを待っている道具（無ければ null）、held は kind に持ち替えてからのコマ数
- 不変: using は 0 以上の整数。left は 1 以上（使い終えたときの残り frames 以下）。using が 1 以上の間、left は減らない。held は 0 以上 SWAP_FRAMES（15）以下。next は kind と違う

契約: grab(grip, kind, frames = PROP_FRAMES) / relax(grip, kind, frames = PROP_FRAMES) / decay(grip)（props.ts。2026-10-07 に新設。2026-10-08 に frames を追加）
- grab の事後: 見せる道具は S13・S14・S16・S17 のとおり（なしからは kind、held 0）。using: 前の using（なしなら 0）+ 1, left: frames
- relax の事後: 見せる道具は grab と同じ。using: max(0, 前の using（なしなら 0）− 1), left: frames
- decay の事後: なしならなし。見せる道具は S15・S18 のとおり進める。そのうえで using が 1 以上なら left はそのまま。left が 2 以上なら left − 1。left が 1 ならなし
- 不変: 引数を変更しない

契約: propFor(tool, command?)（2026-10-07 に command を追加）
- 事前: tool はツール名。command は Bash のコマンド（Bash 以外では渡さない）
- 事後: 道具の対応表のツールならその道具（'hammer'・'magnifier'・'flag'・'hourglass'・'pencil'・'flask'）、それ以外は null。Bash は command がテストを走らせるときだけ 'flask'
- 不変: command が文字列でなければ、テストを走らせないものとみなす

契約: propPixels(id, side, owner)・propBitmap(id, side)（props.ts。2026-10-07 に propPixels を新設）
- propPixels の事後: 高さ 6 の、ピクセルごとの色（0xRRGGBB）か空き（null）。どの道具も道具の色（絵に `#` があればそこだけ owner の色。今は使っていない）。side が left なら左右反転
- propBitmap の事後: propPixels の塗られているところ
- 不変: 引数を変更しない

契約: PROP_GAP・reach(grip)（props.ts。2026-10-07 に新設）
- PROP_GAP: 道具を絵の端の塗りから空けるピクセル数（1）。sprite.ts の描く位置（R5）と、行列の間隔（parade の R4）の両方がこの値を使う
```
