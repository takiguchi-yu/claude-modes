# clawd-wander: 道具を持つ

マスコットが、いま使っているツールに合わせて道具を持って歩く。編集中はハンマー、調べ物中は虫めがね。

**Status:** done（2026-10-06。ハンマー〈左向きの反転を含む〉と虫めがねを画面で確認済み）
**Blocked by:** なし

## 要件

1 コマ = 100 ms。「呼び出し元」は本体（`agentId` の無い `tool.call`）か、その `agentId` の仲間。

```text
R1  [WHEN]   編集系ツール（Edit・Write・MultiEdit・NotebookEdit）の呼び出しが始まる・終わるとき、帯は呼び出し元の 1 体にハンマーを持たせ、残りを 30 コマ（3 秒）にする。
R2  [WHEN]   調べる系ツール（Read・Grep・Glob・WebSearch・WebFetch）の呼び出しが始まる・終わるとき、帯は呼び出し元の 1 体に虫めがねを持たせ、残りを 30 コマにする。
R3  [WHEN]   R1・R2 以外のツールの呼び出しがあったとき、帯は持っている道具も残りコマも変えない。
R4  [WHEN]   道具の残りが尽きたとき、帯はその 1 体の道具をしまう。
R5  [WHILE]  道具を見せている間、帯は道具を向いている側（左向きなら左、それ以外は右）に、絵の端から 1 ピクセル空けて描く。左に描くときは道具の絵を左右反転する。
R6  [WHILE]  ハンマーを見せている間に歩いているとき、帯はハンマーを脚のコマに合わせて 1 ピクセル上下させる。
R7  [WHILE]  道具を持っている間も、帯はその 1 体の歩き方を変えない。
R8  [IF]     驚いている場合、または出入りの途中（現れかけ・跳ねる・消えかけ）の場合、帯は道具を描かない（残りコマは減り続ける）。
R9  [KEEP][WHEN] ツールの呼び出しが始まる・終わるとき、帯は引き続き呼び出し元の居眠りを起こし、失敗なら驚かせる（.scratch/emotes/spec.md）。
R10 [KEEP][WHEN] 顔ぶれにいない id のツールが呼ばれたとき、帯は引き続き誰にも何もしない。
```

道具を持つと活動の途切れは 0 に戻る（R9）ので、道具を持ったまま居眠りすることはない。

## デシジョンテーブル（このコマに道具を描くか）

| | T1 | T2 | T3 | T4 |
| --- | --- | --- | --- | --- |
| 出入りの状態が「いる」 | F | T | T | T |
| 驚いている | - | T | F | F |
| 道具の残りが 1 以上 | - | - | F | T |
| 道具を描く | | | | X |
| 道具を描かない | X | X | X | |

覆う組み合わせ: T1 = 4、T2 = 2、T3 = 1、T4 = 1、計 8 = 2 × 2 × 2。重なりなし。

## 契約

```text
契約: wield(crew, id, tool)
- 事前: tool はツール名
- 事後: tool が R1・R2 のツールなら、id の 1 体の道具がその道具で残りが 30。それ以外は変わらない
- 不変: crew を変更しない。id がいなければ同じ顔ぶれを返す（R10）

契約: propFor(tool)
- 事後: R1 のツールなら 'hammer'、R2 のツールなら 'magnifier'、それ以外は null

契約: Actor.prop（追加）
- 値: undefined | { kind: 'hammer' | 'magnifier'; side: 'left' | 'right'; raised: boolean }
- 事後: 道具は絵の左右の端の塗りから 1 ピクセル空けて、帯からはみ出さない範囲で描く。raised なら 1 ピクセル上げる
```
