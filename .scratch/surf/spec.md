# clawd-wander: Clawd がたまに波乗りする

うろうろするだけでは単調なので、本体の Clawd がひとりで歩いている間、ときどき板に乗って波に乗る。
後ろに波が立ち、Clawd は板に乗って 1 ピクセル浮き、足元に水面が続く。帯の端に着くと波が引いて、また歩き出す。

**Status:** done（2026-10-08。テストで確認。vhs の録画で、乗り出し・滑走・波が引く・降りるまでと、板の下の色・泡が崩れないことを確認。波の形はユーザーが GIF を見て今のままに決めた）
**Blocked by:** なし

## 要件

1 コマ = 100 ms。「ひとり」は、顔ぶれに本体のほかに誰もいない（現れかけ・消えかけの仲間もいない）こと。
「奥行き」は、本体が向かう側の帯の端までの距離（ピクセル）。本体は帯の広いほう（行列と同じ決め方）へ向かう。

```text
R1  [WHEN]  ひとりで、歩ける（いる・驚いていない・居眠りしていない）本体が、行列も波乗りもしていないコマに、
            凪（なぎ。R12）が CALM_FRAMES（450 コマ = 45 秒）以上たまっていて、広いほうの奥行きが MIN_RIDE（30 ピクセル）以上あれば、
            帯は SURF_CHANCE（1/150）の確率で波乗りを始める（凪がたまってから平均 15 秒。合わせておよそ 1 分に 1 回）。
R2  [WHILE] 波に乗っている間、帯は本体を広いほうへ 1 コマ 3 ピクセル進め、その向きを向かせ、自分では歩かせない。
R3  [WHEN]  波に乗っている本体が、次のコマで帯の端を越えるとき、帯は本体をその場で止め、波を引かせ始める（EBB_FRAMES = 6 コマ）。
R4  [WHILE] 波が引いている間、帯は本体を板に乗せたまま止め、波と、板の真下を除く水面を 6 コマかけて薄くする（板と板の真下の水面は残す）。
R5  [WHEN]  波が引ききったとき、帯は本体を板から降ろし、5〜15 コマ立ち止まらせてから、また自分で歩かせる。
R6  [WHEN]  波乗り（乗る・引く）の間に仲間が顔ぶれに加わったとき、帯は波を引かせ始める（乗っている途中なら、その場で止める）。
R7  [WHEN]  波乗りの間に本体が歩けなくなった（驚いた・居眠りした）、または引っ込められたとき、帯はその場で波乗りをやめる（波も板も消す）。
R8  [WHILE] 波乗りの間、帯は本体の道具を描かない（使っている呼び出しの数と残りは props の仕様のとおりに変わり続ける）。
R9  [WHILE] 波乗りの間、帯は次の形を描く（右へ進むとき。左へ進むときは左右反転）:
            本体は 1 ピクセル浮かせ、脚の代わりに板（黄 0xf2c94c、本体の幅＋2）を描く。
            板の下の行に、波の後ろの端から板の先＋2 ピクセルまで、切れ目の無い水面（青 0x4a90d9）を描く。
            本体の後ろに、本体の側へ傾いた波（青、幅 14 ピクセル・高さ 6 ピクセル。頂上の 3 ピクセルは白い泡 0xe8f4ff）を描く。
R10 [KEEP]  波乗りしていない間の歩き方・行列・居眠り・驚き・道具・出入りは変わらない。
R11 [WHILE] 波乗り（乗る・引く）の間、帯は行列を始めない（仲間が加わって引いている間に行列が始まり、本体が板ごと動かないように）。
R12 [WHILE] ひとりで、歩ける本体が、行列も波乗りもしていない間、帯は 1 コマごとに凪を 1 ためる（CALM_FRAMES で止める）。
            波乗りを終えたとき・やめたとき（R5・R7）と、本体が消えきったとき、帯は凪を 0 に戻す。仲間がいる間・歩けない間は、凪をためも戻しもしない。
```

凪（R12）を設けたのは、テストから乱数（`Math.random`。テストでは書き換えられない）を決められないため。凪がたまるまでは決して始まらないので、
45 秒より短いテストでは偶然の波乗りで道具が隠れることが無い（はじめは凪なしの 1/600 で実装し、既存のテストが 2 回に 1 回ほど落ちたので直した）。

## デシジョンテーブル（このコマに波乗りを始めるか。R1）

| | T1 | T2 | T3 | T4 | T5 | T6 | T7 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| ひとり | F | T | T | T | T | T | T |
| 本体が歩ける | - | F | T | T | T | T | T |
| 行列・波乗りをしていない | - | - | F | T | T | T | T |
| 凪 ≥ CALM_FRAMES | - | - | - | F | T | T | T |
| 広いほうの奥行き ≥ MIN_RIDE | - | - | - | - | F | T | T |
| 乱数 < SURF_CHANCE | - | - | - | - | - | F | T |
| 始める | | | | | | | X |
| 始めない（乱数を使わない） | X | X | X | X | X | | |
| 始めない（乱数を使った） | | | | | | X | |

覆う組み合わせ: T1 = 32、T2 = 16、T3 = 8、T4 = 4、T5 = 2、T6 = 1、T7 = 1、計 64 = 2⁶。重なりなし。
条件を満たさないときは乱数を使わない（行列の lineUp と同じ。ほかの乱数の並びを変えない）。

| --- | --- | --- | --- | --- |

## 契約

```text
契約: Surf（surf.ts。Member.surf の型）
- 値: null | { heading: 'left' | 'right'; ebb: number | null }（凪は Member.calm に数える。本体だけが使う）
- ebb が null なら乗っている、数なら引いている（残りコマ。1〜EBB_FRAMES）
- 不変: 本体だけが持つ。仲間は常に null

契約: paddleOut(crew, random, canvas, timing = DEFAULT_TIMING)（crew.ts）
- 事後: デシジョンテーブルの T7 なら、本体の surf が { heading: 広いほう, ebb: null } になり、本体がその向きを向く。それ以外は crew そのもの
- 不変: crew を変更しない。T1〜T5 では random を呼ばない

契約: surfPixels(heading, fade)（surf.ts）
- 事前: fade は 0〜1（引いている間の濃さ。乗っている間は 1）
- 事後: 本体の左端を 0 とした、板・水面・波・泡のピクセル（dx, y, color）の一覧。左へ進むときは本体の幅で左右反転する。fade が 1 未満なら、波と、板の真下を除く水面のピクセルを決まった順に間引く（板と板の真下の水面は残す）
- 不変: 引数を変更しない

契約: Actor.surf（sprite.ts）
- 値: undefined | { heading: 'left' | 'right'; fade: number }
- 事後: 本体を 1 ピクセル浮かせて脚の行を描かず、surfPixels の色で板・水面・波を本体の塗りとして描く
```

## テストとの対応

## 記録（2026-10-08）

- ユーザーの提案「うろうろするだけだとつまらないから、たまに波乗りしてみせる」から。見本から「後ろに波・板・水面」、頻度「1 分に 1 回くらい」、道具「波乗り中は見せない」を選んだ
- 決めたこと（ユーザーに聞かずに決めた）: ひとりのときだけ乗る（仲間がいるときは行列。2 つが同時に起きない）。広いほうへ 1 コマ 3 ピクセル（小走りと同じ速さ）で進み、端で波が引いて歩きに戻る
- 高さ: 帯も Clawd の絵も 6 ピクセルだが、Clawd の絵は最上行が空いているので、1 ピクセル浮かせても頭は切れない。脚の行に板、最下行に水面を描ける
- 録画で見つけて直したこと: 水面の切れ目（4 ピクセルごと）が板の真下に来ると、1 マス（2×2 ピクセル）に板の黄・水の青・空きが入り、
  2 色を出せないので水のピクセルまで黄で描かれ、板の下に黄色い歯が並んで見えた（引いている間に水面を間引いたときも同じ）。
  水面を切れ目なしにし、引いている間も板の真下の水面は残すことにした（R4・R9）。切れ目を動かすための frame はやめた
- 録画で見つけて直したこと（2 つ目）: 泡が 2 ピクセルだと、1 コマ 3 ピクセル進むたびにマスとの位置がずれ、ずれたコマでは泡のマスに空きが入って青で描かれ、
  泡が 1 コマおきに消えた。泡を 3 ピクセルにして、どちらの位置でも泡だけのマスが 1 つは残るようにした（R9）
