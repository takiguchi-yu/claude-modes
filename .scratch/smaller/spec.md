# clawd-wander: マスコットを一回り小さくする

帯を 3 行から 2 行にし、マスコットを縦横とも約 2/3 にする。1 マスを 2×3 ピクセルとみなす文字に替えて、縦 6 ピクセルの描き込みを残す。

**Status:** 取り下げ（2026-10-06。Raster が sextant を受け付けず、ほかの描き方も採らないことにした）
**Blocked by:** なし

## 要件

1 コマ = 100 ms。「1 マス」は端末の 1 文字。

```text
R1  [UBIQ]  帯は 1 マスを横 2 × 縦 3 ピクセルとみなし、2×3 ブロック文字（Unicode の sextant U+1FB00〜U+1FB3B と、空白・▌・▐・█）1 文字で描く。帯の高さは 2 行。
R2  [UBIQ]  歩く絵は高さ 6 ピクセル、幅をいまの約 2/3（Clawd 12・おばけ 7・ロボット 7・宇宙人 8・キノコ 7・恐竜 8・ネコ 8）にし、目と 2 コマの足踏みを持つ。
R3  [WHILE] 居眠りしている間、帯はその 1 体を、高さ 3 ピクセル（帯の下の行ちょうど）・幅は歩く絵の 8 割以下・目を閉じた寝姿にする。足元と左右の中央は歩く絵にそろえる。
R4  [WHILE] 居眠りしている間、帯は寝姿の右横の下の行に「z」を描き続け、その右上（上の行・1 マス右）の「Z」を 5 コマごとに出し入れする。
R5  [UBIQ]  道具の絵は高さ 6 ピクセルのまま、幅をハンマー 3・虫めがね 5 にする。
R6  [KEEP][WHILE] 驚いている間、帯は引き続き高さ 6 ピクセルのドット絵の「!」を描く。
R7  [KEEP][UBIQ]  歩く・浮く・薄くなる量はピクセル単位のまま変えない（1 ピクセルは横が半マス、縦が 1/3 マスになる）。
```

R3・R4 は .scratch/emotes/spec.md の R5（高さ 4 の寝姿、zZ を 1 行上下させる）を置き換える。帯が 2 行になり、zZ を 1 行上げると Z が帯からはみ出すため。

## 契約

```text
契約: SPRITE_ROWS（変更）
- 値: MASCOT_HEIGHT / 3 = 2

契約: Mascot.width（変更）
- 値: R2 の幅。WIDEST は 12

契約: paint(actors, columns)
- 事後: 返す cells は columns × SPRITE_ROWS マス。ピクセルの絵のマスは R1 の文字のどれか
```

## テストとの対応

- [ ] R1・契約 paint: 2×3 ピクセルが R1 の文字 1 つに対応し、64 通りがすべて別の文字になる
- [ ] R1・R2: 正面・直立の Clawd が、ロゴを縮めた決まった形（2 行）で描かれる
- [ ] R2: どの絵も高さ 6・幅が R2 の値・足が最下行・歩くと絵が変わる（既存のテストを更新）
- [ ] R3: 寝姿は上 3 行が空き、足元は下端、幅は 8 割以下、左右は中央
- [ ] R4: z は下の行、Z は high のときだけ右上に出る
- [ ] R5: ハンマーの頭（幅 3）と虫めがね（幅 5）の位置（既存のテストを更新）
- [ ] R6: 既存の「!」のテスト
- [ ] R7: 既存の歩く・浮く・薄くなるのテスト

## 取り下げ（2026-10-06）

- 実装してテストを回したところ、Raster が sextant を拒否した: `Raster "clawd" cell 6 holds code point 129822, beyond the Basic Multilingual Plane`。型定義にも「A code point is one printable width-1 BMP character (blocks, box drawing, braille too)」とある（plugin-authoring の `types/claude-code.d.ts:8953`、2.1.291）
- 文字の対応表そのものは正しかった（Python の unicodedata 13.0.0 で 60 文字すべて名前と一致）。使えないのは Claude Code の制約による
- 代わりの案として、点字（U+2800〜、1 マス 2×4 点。BMP の中にある）と、いまの 2×2 のまま縦 4 ドットに描き直す案を見せたうえで、いまの大きさのままにすると決まった。コードは `git checkout` でコミット済みの状態に戻した
- 決めていたこと（再開するときの参考）: 寝姿は高さ 3 ピクセルで下の 1 行にちょうど収める、居眠りの Z は上下させずに右上で出し入れする
