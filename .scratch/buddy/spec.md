# clawd-wander: ちび Clawd たち

Clawd が 1 体だけで作業している間、小さい Clawd（ちび Clawd）が Clawd のあとをついて歩く。作業が続くと 1 匹ずつ増える。サブエージェントの仲間が来たら、ちび Clawd はいなくなる。

**Status:** 取り下げ（2026-10-07。画面で確かめながら作り直したうえで、機能ごと削除した）
**Blocked by:** なし

## 要件

1 コマ = 100 ms。ちび Clawd の絵は幅 6・高さ 2 ドット（体と腕。足は無い。左右対称）。
「道筋」は本体の真ん中が通った x を 1 ドットずつ覚えたもの（.scratch/parade/spec.md の道筋と同じ仕組み）。

```text
R1  [WHEN]  本体が現れ始めるとき、帯はちび Clawd を 0 匹にし、作業の経過を 0 に戻し、道筋を本体の後ろ（向きの反対側。正面なら左）へまっすぐ用意する。
R2  [WHILE] 本体が「いる」間、帯は 1 コマごとに作業の経過を 1 増やし、ちび Clawd の数を ⌊経過 / 200⌋（最大 30）にそろえる（0 匹から始まり、20 秒ごとに 1 匹ずつ増え、10 分で 30 匹）。足すちび Clawd は、その並び位置に現れかけ（ふわっと）で置く。
R3  [WHILE] 本体が「いる」で、仲間（サブエージェント）が帯に 1 体もいない間、帯はちび Clawd を出す（現れかけ・いるにする）。
R4  [WHEN]  仲間が帯に現れたとき、または本体が「いる」でなくなったとき、帯はちび Clawd を引っ込める（「いる」ちび Clawd は本体と同じく跳ねてから消えかけ、現れかけのちび Clawd はその濃さから消えかけ）。
R5  [WHILE] 本体が「いる」間、帯は本体の真ん中が通った位置を道筋に足す。
R6  [WHILE] 本体が「いる」で起きている間、帯は「いる」ちび Clawd を、k 番目（1 から）の目標へ 1 コマ 4 ドットまで進める。
           目標は、道筋を D(k) さかのぼった位置にちび Clawd の真ん中が来る x。D(1) = 本体の幅 / 2 + ちび Clawd の幅 / 2 + 2、D(k) = D(k−1) + ちび Clawd の幅 + 2。目標はちび Clawd が帯に収まる範囲に寄せる。
R7  [WHILE] 動いている間は、動いたコマ数が奇数のコマだけ 1 ドット浮かせる（ぴょこぴょこ跳ねて歩く）。動かないコマは本体のほうを向いて、浮かせない。
R8  [WHILE] 本体が居眠りしている間、帯はちび Clawd も寝姿にして動かさない。
R9  [WHILE] ちび Clawd が現れかけ・消えかけの間、帯はそのちび Clawd を動かさず、本体の出入りと同じ見え方（濃さ・浮き）で描く。
R10 [WHEN]  消えきったちび Clawd をまた出すとき、帯はそのちび Clawd を並び位置に置き直してから現す。
R11 [ALWAYS] 帯はちび Clawd を、本体と仲間より奥に描く（本体の「!」・道具を隠さない）。
R12 [KEEP][ALWAYS] ちび Clawd は顔ぶれ（サブエージェントの数・種類・色の割り当て）に入らない。
```

ちび Clawd は本体が通った道をあとからたどるので、本体より前に出ない。本体が引き返すと、ちび Clawd は折り返し点まで来てから引き返すので、本体とすれ違う。ちび Clawd は奥に描くので本体の形は欠けず、ちび Clawd が本体の後ろを通り抜けて見える（.scratch/overlap/spec.md の 1 ドット空け）。

## 状態遷移表（ちび Clawd 1 匹）

出入りは .scratch/fade-in/spec.md の状態遷移（いない・現れかけ・いる・消えかけ）をそのまま使う。出す・引っ込めるのきっかけは R3・R4。

| 現在 \ 出来事 | 出す（R3） | 引っ込める（R4） | 1 コマ進む |
| --- | --- | --- | --- |
| いない | S1 → 並び位置に置き直して現れかけ（R10） | S2 → いない | S3 → いない |
| 現れかけ | S4 → 現れかけ | S5 → 消えかけ | S6 → 濃くなる。12 コマでいる（動かない、R9） |
| いる | S7 → いる | S8 → 跳ねる（4 コマ）→ 消えかけ（本体と同じ） | S9 → 目標へ進む（R6）。本体が居眠り中なら動かない（R8） |
| 消えかけ | S10 → 現れかけ | S11 → 消えかけ | S12 → 薄くなる。12 コマでいない（動かない、R9） |

## 契約

```text
契約: Member.brood（Member.buddy を置き換え）
- 値: null | Brood。本体だけが持ち、仲間は常に null

契約: buddy.ts
- hatch(centerX, heading, maxCenter): R1 のちび Clawd たち（0 匹・経過 0・道筋）
- tend(brood, leader, solo, maxX): 1 コマ（R2〜R10）。leader は本体の真ん中・幅・状態（いる・起きている）、solo は仲間がいないか、maxX はちび Clawd を置ける x の最大
- 事後: ちび Clawd は 30 匹まで。「いる」ちび Clawd の 1 コマの移動は 4 ドット以内。x は 0〜maxX

契約: Actor.back
- 値: undefined | true。true の Actor は、paint でほかの Actor より先に（奥に）描く
```

## テストとの対応

- [x] R1・R2: 現れ始めは 0 匹で、20 秒たつと 1 匹目が現れかけになる
- [x] R2: 20 秒ごとに 1 匹ずつ増え、30 匹で止まる
- [x] R3・R4・R10: 仲間が来ると消え始め、仲間がいなくなると並び位置に戻って現れる。本体が消え始めるとちび Clawd も消え始める
- [x] R6・契約 TRAIL: 30 匹そろっても全員が隙間 2 で並ぶ
- [x] R5・R6: 本体が歩くと、ちび Clawd は順に本体の後ろへ並び、本体より前に出ない。1 コマ 4 ドットまで
- [x] R7: 歩くと 1 コマおきに 1 ドット跳ね、止まると本体のほうを向いて浮かない
- [x] R8・R9: 居眠り中は寝姿で動かず、現れかけの間も動かない
- [x] R11: いちばん奥に描かれ、本体の「!」を隠さない
- [x] R12: 仲間の数・割り当ては変わらない（既存のテスト）
- [x] 絵: ちび Clawd も高さ 6・最下行が塗られている・寝姿の決まり（既存のマスコットのテスト。歩きは絵ではなく跳ねる動きなので「歩くと絵が変わる」は除く）
