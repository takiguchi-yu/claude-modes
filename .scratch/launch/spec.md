# clawd-wander: 仲間が本体から飛び出す

サブエージェントが起動したとき、仲間が本体の Clawd から弧を描いて飛び出し、着地してから歩き出す。

**Status:** 取り下げ（2026-10-06。画面で確認したうえで、機能ごと削除した）
**Blocked by:** なし

## 要件

1 コマ = 100 ms。F = 10 コマ（1 秒）。

```text
R1  [WHEN]  サブエージェントの起動の知らせ（agent.spawn）を受けたとき、本体が「いる」なら、帯は新しい仲間を本体の真ん中に置き、F コマかけて着地点まで飛ばす。
R2  [WHILE] 飛んでいる間、帯は仲間の x を出発点から着地点へ等速で動かし、浮きを 0 → 2 → 0 ピクセルの弧にする。濃さは 1、正面向き・直立で歩かせない。
R3  [WHEN]  飛び始めて F コマ経ったとき、帯は仲間を着地点に置いて「いる」にし、次のコマから歩かせる。
R4  [WHEN]  飛んでいる間に一覧から外れたとき、帯はその仲間をその場で濃さ 1 から消え始めさせる（消えかけ・残り 12 コマ）。
R5  [KEEP][WHEN] 起動の知らせを受けたとき本体が「いる」でなければ、帯は引き続き仲間をランダムな位置に上からふわっと現す。
R6  [KEEP][WHEN] 一覧の見直しで新しい仲間が見つかったとき、帯は引き続き上からふわっと現す（飛ばさない）。
R7  [KEEP][WHEN] 消えかけの仲間がまた出されたとき、帯は引き続きその濃さから現れ直す（飛ばさない）。
R8  [KEEP][WHEN] 仲間が加わるとき、帯は引き続き、まだいない種類と色を割り当て、着地点をランダムに選ぶ。
```

## 状態遷移表（.scratch/fade-in/spec.md・.scratch/emotes/spec.md に「飛んでいる」を足す）

| 現在 \ イベント | 出す | 引っ込める | 1 コマ進む |
| --- | --- | --- | --- |
| 飛んでいる（残り f） | S16 → 飛んでいる（何もしない） | S17 → 消えかけ（残り 12） | S18 → f = 1 ならいる、それ以外は飛んでいる（残り f − 1） |

- 飛んでいる状態に入るのは R1 だけ（launch）。いない → 飛んでいる の遷移を「出す」には含めない
- 見え方: 濃さ 1、浮きは経過 p = (F − f) / F に対して round(8 × p × (1 − p))（最大 2）
- 起動の知らせ（join）では、飛んでいる仲間も「出している」ものとして扱う

## 契約

```text
契約: launch(crew, id, random, canvas)
- 事前: canvas は帯の幅（ピクセル）
- 事後: id が新しい仲間で本体が「いる」なら、その仲間は飛んでいる（残り F）、x は本体の真ん中に絵の真ん中をそろえた位置、
        着地点は 0 以上 canvas − 絵の幅 以下。それ以外は join と同じ結果
- 不変: crew を変更しない

契約: Member.flight（追加）
- 値: null | { from: number; to: number }。飛んでいる間だけ値を持ち、「いる」になったら null
```

## テストとの対応

- [x] R1・契約 launch: 本体が「いる」なら、新しい仲間は本体の真ん中から飛び始める
- [x] R2・R3・S18: 等速で着地点へ進み、浮きは 0 → 2 → 0、F コマで着地する（着地後は「いる」になるので、歩くのは既存の歩行のテストで確認）
- [x] R4・S17: 飛んでいる途中で外れると、その場で消え始める
- [x] S16: 飛んでいる間に出しても変わらない
- [x] R5: 本体がいなければ、上からふわっと現れる
- [x] R6・R7: 一覧の見直し・消えかけからの出し直しでは飛ばない
- [x] R8: 既存の種類・色・位置の割り当てのテスト
- [x] register: 実際の agent.spawn で、仲間が最初のコマから濃さ 1 で描かれる
