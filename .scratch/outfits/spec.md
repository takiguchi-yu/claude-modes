# clawd-wander: Clawd の飾り（王冠・サングラス・ヘッドフォン・小鳥）

Clawd に見た目のバリエーションを持たせる。現れるたびに、飾りなし・王冠・サングラス・ヘッドフォン・小鳥のどれか 1 つを付けて出てくる。
見本はユーザーが添付した画像（5 体の Clawd が王冠・三角帽・白いサングラス・ヘッドフォン・頭の横を飛ぶ小鳥と細目）。

**Status:** done（2026-10-09。テストで確認。paint の出力を端末に描いて vhs で撮り、5 種類の飾りを向き・x の偶奇・寝姿・道具を持つときで確認）
**Blocked by:** なし

## 前提

- 帯の高さは 6 ピクセル（3 行）のまま。Clawd の上に空いているのは 1 行（y = 0）だけなので、飾りは y = 0 と、本体に白を重ねて描く。
  帯を高くする案は採らない（2026-10-06 にユーザーは帯を小さくしたがっていた。.scratch/smaller/spec.md）
- 1 マス（横 2 × 縦 2 ピクセル）は文字の色と背景の色の 2 色までしか描けない。空き・持ち主の色・白の 3 つが 1 マスに入ると、
  paint はマスの中を多いほうの 1 色で塗るので形が崩れる。道具が絵から 1 ピクセル空けて描くのと同じ理由（.scratch/props/spec.md の R5）
- 飾りの白は OUTFIT_COLOR（0xf2f0eb）

## 要件

1 コマ = 100 ms。「現れ始める」は、本体が消えきった状態（gone）から現れかけになること。

```text
R1  [WHEN]  本体が現れ始めるとき、帯は飾りを、なし・王冠・サングラス・ヘッドフォン・小鳥の 5 通りから同じ確率で 1 つ選ぶ（2026-10-09 に三角帽を外した）。
R2  [WHILE] 本体が現れかけ・いる・跳ねる・消えかけの間、帯は飾りを変えない（消えかけから現れ直しても選び直さない）。
R3  [WHERE] userConfig の outfits が false の構成では、帯は本体に飾りを付けない（既定はオン。/config で変えられる）。
R4  [ALWAYS] 帯は仲間（サブエージェント）に飾りを付けない。
R5  [WHILE] 飾りを付けている間、帯は飾りの絵（下の表）を OUTFIT_COLOR で、本体の絵の上に重ねて描く。
R6  [IF]    浮き（跳ねる・現れかけ・消えかけ・ぽよん・波乗り）が 1 ピクセル以上ある場合、または押しつぶされている場合、帯は飾りの白い部分を描かない。
            浮くと縦のマスの組み合わせがずれ、白が目の穴と同じマスに入って R9 を守れないため。
R7  [WHILE] 小鳥を付けている間、帯は小鳥を本体の背中側（右向きなら左、それ以外は右）の頭の横に描く。
R8  [IF]    小鳥を付けた本体が驚いている場合、または小鳥と同じ側に道具を描く場合、帯はそのコマの小鳥を描かない。
R9  [WHILE] 小鳥を付けた本体が居眠りしている間、帯は小鳥を寝姿の頭の上にとまらせて描く。
R10 [WHILE] サングラスを付けた本体が居眠りしている間、帯はサングラスを描かない（寝姿には目が無い）。
R11 [WHILE] 小鳥を付けている間、帯は本体の目を横長（2 ピクセル）の細目にする。押しつぶされている間を除き、浮いていても細目のままにする。
R12 [ALWAYS] 浮きが 0 のコマでは、帯は飾りを付けた本体のどのマスにも、空き・持ち主の色・白の 3 つを同時に入れない（x の偶奇によらない）。
            小鳥はこれを形だけでは守れないので、決まった列が帯で偶数ピクセルに来るよう、奇数のときは 1 ピクセルずらして描く。
R13 [WHILE] 本体が薄くなっている間（浮きが 0 の消えかけの最初のコマ）、帯は飾りも本体と同じ順番で間引く。
R14 [KEEP][ALWAYS] 飾りなしの本体は、引き続きいまと同じ絵で描く。
R15 [KEEP][ALWAYS] 歩き方・出入り・道具・記号・行列・ひとり遊びは、引き続き飾りによって変わらない。
```

小鳥は 1 行目の白が頭と同じマスに入らないよう、頭から 1 ピクセル空ける位置にそろえる。

### 飾りの絵

立ち姿（歩きの 2 コマも同じ）。`#` が白、`o` は白で塗らずに残る本体の橙、`.` は空き。x は絵の左端（0）から 17 まで。
本体の頭は y = 1・2 で x = 3〜14、目の穴は y = 2。寝姿の頭は y = 2 で x = 5〜12。

| 飾り | 立ち姿 | 寝姿 | 偶数にそろえる列 |
| --- | --- | --- | --- |
| 王冠 | y0 `...#....##....#...` / y1 `...############...` | y0 `.....#..##..#.....` / y1 `.....########.....` | なし |
| サングラス | y2 に左右のレンズ。各 3 ピクセルで目の穴を含み、x = 4〜13 に収める | 描かない（R10） | なし |
| ヘッドフォン | y0 `...############...` / y1 `..##..........##..` | y0 `.....########.....` / y1 `....#........#....` | なし |
| 小鳥（右） | y0 x = 16・18 / y1 x = 17 | 頭の上: y0 x = 8・10 / y1 x = 9 | 右は x = 16（ずらすなら左へ 1） |
| 小鳥（左） | y0 x = -1・1 / y1 x = 0 | 同上 | 左は x = 0（ずらすなら右へ 1） |

サングラスのレンズは、目の x を e として `max(4, min(11, e - 1))` から 3 ピクセル。小鳥の細目は、左目の x を l・右目を r として
y = 2 の l + 1 と r - 1 も穴にする（前を向くと 5・6 と 11・12）。

## デシジョンテーブル（小鳥の白をこのコマに描くか。R6・R8・R9）

| | T1 | T2 | T3 | T4 | T5 | T6 |

| 浮きが 1 以上か、押しつぶされている | T | F | F | F | F | F |

| 驚いている | - | N/A | T | F | F | F |
| 小鳥と同じ側に道具を描く | - | N/A | - | T | F | F |
| 道具を持っていない | - | N/A | - | N/A | T | F |
| 描かない | X | | X | X | | |

| 背中側の頭の横に描く | | | | | X | X |

覆う組み合わせ: 居眠り中は驚き・道具を描かない（驚きが先。道具は .scratch/props/spec.md の R8）ので T2 の N/A は起こりえない。
T4 の「道具を持っていない」は、同じ側に道具を描く以上 F しかない。T5（道具なし）と T6（反対側に道具）で残りを覆う。重なりなし。

## 契約

```text
契約: OutfitId（outfits.ts）
- 値: 'crown' | 'shades' | 'headphones' | 'bird'

契約: chooseOutfit(random)（outfits.ts）
- 事前: random は 0 以上 1 未満を返す
- 事後: null（飾りなし）か OutfitId。random() を [0, 1) で 5 等分した区間ごとに、null・crown・shades・headphones・bird
- 不変: random を 1 回だけ呼ぶ

契約: outfitLook(outfit, facing, pose)（outfits.ts）
- 事後: { dots, holes, align?, side? }。dots は白く塗る点、holes は本体から抜く点（絵の左端・上端からのピクセル）。
        align は { column, nudge }（R12）。side は小鳥が張り出す側（R7・R8）。寝姿の小鳥・小鳥以外は side を持たない
- 不変: 同じ引数には同じ値を返す

契約: Member.outfit（crew.ts）
- 値: OutfitId | null。仲間は常に null（R4）

契約: setMain(crew, isWorking, dress?)（crew.ts。dress を追加）
- 事後: isWorking で本体が消えきっていて dress があれば、本体の outfit を dress() にする（R1）。それ以外は outfit を変えない（R2）
- 不変: dress が無ければ、いまと同じ（R3 は register.ts が dress を渡さないことで満たす）

契約: Actor.outfit（sprite.ts）
- 値: OutfitId か省略。省略なら飾りなしで、いまと同じ絵（R14）
```
