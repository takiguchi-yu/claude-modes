# clawd-wander: 長い Bash の間にアニメーションが止まる（調査の記録）

テストの実行（フラスコ）や待ち（砂時計）の間に、道具を持ったまま絵が止まることがある、という指摘の調査記録。
**プラグインの外が原因で、プラグインでは直せない（どの層かは未特定）。** 試した見張りタイマーは効かなかったので元に戻した。

**Status:** 取り下げ（2026-10-08。原因はプラグインの外。どの層かは未特定）
**Blocked by:** なし

## 経緯

- 最初の見立て: アニメーションのタイマーが黙って終わり（`$.clock.every` は 1 周期でも拒否されると終わる）、
  張り直すきっかけ（ツール呼び出しの開始・帯の描き直し）が長い呼び出しの間は来ない
- そこで、アニメーションとは別に 1 秒周期の見張りタイマーを立て、互いに張り直す変更を入れた（テストでは確認）
- 実機では効かなかった。下の実測で、タイマーは止まっていなかったことが分かった。変更はコミットせずに元に戻した

## 実測（2026-10-08、同日）

見張りを入れて `/reload-plugins` したあとも、40 秒のテスト（`claude plugin test .` を 8 回）の間、画面の Clawd は固まったままだった（ユーザーが目視。ときどき動く）。計測コードを一時的に入れて測った結果、**原因はタイマーではなかった**。

- テスト中の 40 秒間、ティックは毎秒約 10 コマのまま（tick 60 → 410）。タイマーの張り直し 0 件、`blit` の拒否・失敗 0 件
- 送ったコマの中身も毎秒変わっていた（本体の x が 0〜211 を往復、ハッシュも毎回違う）
- 道具を持たない同じ重さのテスト（`claude plugin "$(echo test)" .`）でも同じように固まった → 道具は関係ない
- そのとき Claude Code 本体の CPU は 4〜6%（10 コア、ロードアベレージ 5〜6）→ CPU 不足ではない
- 毎コマ `$.ui.invalidate('ui.render')` を呼ぶ実験では、エンジンが 40 秒で `ui.render` を 392 回呼び直し、プラグインは毎回新しい Raster を返したが、それでも画面は固まった

結論（この時点）: Bash の実行中、Claude Code 本体がターミナルへの書き出しを止めている、と考えた → 下の「録画での確認」で訂正。プラグインからは直せない。フラスコ・砂時計で目立ったのは、長い Bash（テスト）の間に持つ道具だからで、手ぶらでも同じように止まる。

## 録画での確認（2026-10-08、同日）

元に戻した版（HEAD）を vhs で録画した（`claude --plugin-dir ./clawd-wander`、herdr を通さない）。帯の領域（1100×56 px）を 25fps で切り出し、ピクセルが 30 個以上変わったコマを「動いた」と数えた。

- Read → validate（Bash）→ test（Bash）の 14 秒: 道具は虫めがね → フラスコの順に出た。Bash の間も 1 秒あたり 6〜10 回動いた
- `claude plugin test` を 8 回つないだ 1 回の Bash（約 31 秒）: 2〜34 秒の間、ほぼ毎秒 10 回（ティックの全コマ）動いた。止まったのは 12〜15 秒の約 2 秒だけで、休み（rest、1〜3 秒）の範囲

訂正した結論: **Claude Code 単体では、Bash の実行中も帯は止まらない。** 止まるのはユーザーの端末で、`TERM_PROGRAM=herdr`（0.9.3、AI エージェント向けの端末多重化ツール）が Claude Code と実端末の間で画面を描き直している。herdr が Bash 実行中のペインの描き直しを間引いている可能性が高い（推測。herdr を通した再現はまだ）。

## herdr を通した録画（2026-10-08、同日）

vhs の中で検証用セッション `herdr --session clawd-verify`（HERDR_* を外して、使用中のセッションと切り離した）を起動し、その中で claude（新しく起動した Sonnet のセッション）に `claude plugin test` 8 回の Bash（約 32 秒）を走らせた。帯（850×56 px）の動きは 21〜53 秒の間ほぼ毎秒 10 回。止まったのは 25 秒の約 1 秒と 40〜42 秒の 2〜3 秒だけで、休みの範囲。**herdr を通しても再現しなかった。** 検証用セッションは stop・delete 済み。

| 条件 | 端末 | 多重化 | claude のセッション | 長い Bash 中の帯 |
| --- | --- | --- | --- | --- |
| ユーザーの画面 | Ghostty | herdr 0.9.3 | Opus、71 分続いた長い会話 | 固まる・ときどき動く |
| 録画 1 | vhs（xterm.js） | なし | Sonnet、新規 | 毎秒 10 回動く |
| 録画 2 | vhs（xterm.js） | herdr 0.9.3 | Sonnet、新規 | 毎秒 10 回動く |

残る違いは Ghostty と、長く続いた会話（または Opus）のどちらか。
