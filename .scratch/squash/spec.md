# clawd-wander: 会話の圧縮でぺしゃんこになる

会話が圧縮される（`/compact`・自動の圧縮）間、そのループのマスコットがぎゅっと押しつぶされ、終わったらぽよんと戻る。

**Status:** done（2026-10-08。テストで確認。vhs の録画で、`/compact` の間つぶれて現れ、終わるとぽよんと戻ってから消えることを確認）
**Blocked by:** なし

## 要件

1 コマ = 100 ms。「そのループのマスコット」は、`session.compact` の `agentId` が無ければ本体、あればその仲間。

```text
R1  [WHEN]  会話の圧縮（session.compact。trigger が manual・auto・plugin）が始まるとき、帯はそのループのマスコットを押しつぶす。
            本体がまだ帯に出ていない（消えきっている）ときも押しつぶし、押しつぶされたまま現れさせる（`/compact` は作業の始まりと同時に圧縮が始まり、
            そのときの本体はまだ出ていないため。2026-10-08 に録画で見つけて直した）。
            trigger が precompute（前もって計算するだけで、会話は変わらない）のときは何もしない。
R2  [WHILE] 押しつぶされている間、帯はその 1 体を歩かせず、絵を縦に半分（6 行を上から 2 行ずつまとめた 3 行）にして足元にそろえ、左右に 1 ピクセルずつ広げて描く。
            道具・記号（驚き・居眠り）は描かない。
R3  [WHEN]  圧縮が終わったとき（成功・取りやめ・例外のどれでも）、帯はその 1 体をぽよんと戻す: 5 コマかけて浮きを 1・1・0・1・0 にし、それから歩かせる。
            戻るのは活動なので、居眠りの途切れも 0 に戻す。
R4  [WHILE] 押しつぶされている・戻っている間、帯は行列・波乗りを始めず、乗っている波乗りはやめる（.scratch/surf/spec.md の R7）。
R5  [WHEN]  押しつぶされている 1 体が引っ込められたとき（跳ねる・消えかけになったとき）、帯は押しつぶしをやめ、ふつうどおり跳ねて消える。
            消えきっている間・現れかけの間は、押しつぶしを続ける。
R6  [IF]    押しつぶされていない 1 体の圧縮の終わりが届いた場合、帯は何もしない。
R7  [WHILE] 本体が押しつぶされている・戻っている間、帯は作業が終わっていても本体を引っ込めない（戻りきってから消える）。
            2026-10-08 に追加（`/compact` は圧縮の終わりと作業の終わりが同時なので、戻る前に消えて「ぽよん」が見えなかった。ユーザーの希望）。
```

## 契約

```text
契約: Squash（squash.ts。Member.squash の型）
- 値: null | { kind: 'pressed' } | { kind: 'spring'; left: number }（left は 1〜SPRING_FRAMES）

契約: squeeze(crew, id) / unsqueeze(crew, id)（crew.ts）
- squeeze の事後: id の 1 体が顔ぶれにいれば（消えきっている本体も含む）、squash が pressed になる（S1・S5・S9）
- unsqueeze の事後: id の 1 体が pressed なら spring（残り SPRING_FRAMES）になり、途切れが 0 に戻る（S6）。それ以外は変わらない（S2・S10）
- 不変: crew を変更しない。id がいなければ同じ顔ぶれを返す

契約: flatten(bitmap)（squash.ts）
- 事前: bitmap は高さ 6
- 事後: 高さ 6・幅は元 + 2。上 3 行は空き、下 3 行は元の 2 行ずつの OR を左右に 1 ピクセル広げたもの
- 不変: 引数を変更しない

契約: wantsMain(crew, isWorking)（crew.ts）
- 事後: 作業中か、仲間が動いているか（.scratch/always/spec.md の R1）、本体が押しつぶされている・戻っている（R7）なら true

契約: Actor.squashed（sprite.ts）
- 値: undefined | true
- 事後: 絵を flatten した形で、x を 1 ピクセル左にずらして描く（広げた分を左右に振り分ける）
```

## テストとの対応

- [x] R1・R3・register: 圧縮の間は帯の上 3 行に何も描かれず、終わると元の高さに戻る。テストでは、圧縮を別のプラグインから起こし（`$.session.compact` は呼んだプラグインのフックを通らないため）、テストからの圧縮には会話が付かないので 1 通だけの会話を足す。manual・auto も同じ分岐を通る。precompute で何もしないことはテストから起こせない（trigger は書き換えられない）ので、register.ts の分岐を読んで確かめた
- [x] R2・契約 flatten・Actor.squashed: 下 3 行に縮み、左右に 1 ピクセル広がる。押しつぶされている間は歩かず、道具・記号を描かない
- [x] R3・S6・S11: 圧縮が終わると 5 コマ浮き 1・1・0・1・0 で戻り、途切れが 0 に戻り、また歩く
- [x] R4: 押しつぶし・戻りの間は行列・波乗りを始めず、乗っている波乗りはやめる
- [x] R5・S8・S12: 引っ込められるとやめる
- [x] R6・S2・S10: 押しつぶされていない 1 体の終わりでは何もしない
- [x] R7・契約 wantsMain: 押しつぶし・戻りの間は作業していなくても本体を出し、戻りきったら出さない
- [x] R7・register: 作業が終わってから圧縮が終わっても、ぽよんと戻ってから消える
