# clawd-wander: 重なっても見分けられるようにする

マスコットどうしが重なったとき、手前の子の周り 1 ドットを奥の子から消して、2 体の輪郭を切り離す。動きは変えない（すれ違える）。

**Status:** done（2026-10-06。テストで確認。2026-10-08 に vhs の録画で、手前の子の周りの奥の子のドットが消え、2 体を見分けられることを確認。ただし奥の子の道具は消えずに残り、手前の子が持っているように見えることがある〈下の記録〉）
**Blocked by:** なし

## 要件

「塗り」は、その 1 体が描くドットすべて（絵・道具・「!」）。「1 ドット以内」は上下左右と斜めの隣（チェビシェフ距離 1）。

```text
R1  [WHEN]  1 体を描くとき、帯はその塗りから 1 ドット以内にある、先に描いた者のドットを消してから、その塗りを描く。
R2  [KEEP][ALWAYS] 手前・奥は描く順のまま（後に描く者が手前。顔ぶれの順なので、仲間は本体より手前、仲間どうしは後に来た者が手前）。
R3  [IF]    手前の者が薄くなっている途中（濃さ 1 未満）の場合、帯は奥の者のドットを消さない（間引かれたまばらな塗りで、奥の子に穴が開かないように）。
R4  [ALWAYS] 濃さ 1 の者どうしは、重なっても 1 マス（2×2 ドット）に 2 体のドットが入らない（R1 の隙間が 1 ドットあるため）。
R5  [KEEP][ALWAYS] 重なっていない者の見え方は変わらない。居眠りの z・Z（マスに置く文字）は変わらない。
```

2026-10-06、画面で「すれ違うときや重なったときに見づらい」との指摘。いまは後に描く者のドットで上書きし、1 マスに 2 色が入ると多いほうの色にするので、2 体が 1 色の塊に見えていた。
「出会ったら引き返す」案は、何度出会っても並び順が変わらず反対側へ行けなくなるので採らなかった。

## 契約

```text
契約: paint(actors, columns)（事後条件を追加）
- 事後: 濃さ 1 の Actor の塗りから 1 ドット以内には、それより前の Actor のドットが無い（R1・R4）
```

## テストとの対応

- [x] R1: 仲間が本体に重なると、仲間の塗りから 1 ドット以内の本体のドットが消え、それ以外は残る
- [x] R2: 後に描いた者が手前（入れ替えると消える側も入れ替わる）
- [x] R3: 手前が薄くなっている途中なら、奥のドットは消えない
- [x] R4: 濃さ 1 の 2 体が重なっても、どのマスにも 2 体のドットが入らない
- [x] R5: 既存の描画のテスト

## 記録（2026-10-06）

- 実装: `sprite.ts` の `paint`。Actor ごとに塗るピクセルを集め、濃さ 1 なら周り 1 ピクセルにある先の Actor のピクセルを消してから描く（ピクセルごとに描いた Actor の番号を持つ）
- 検証: `claude plugin validate` 通過、`claude plugin test` 70 件すべて成功（追加 3 件）、`tsc` 終了コード 0
- 決めたこと: 手前・奥は今の描き順のまま（仲間が本体より手前）。小さい仲間が手前のほうが、大きい本体の形も周りに残って両方見える。隙間が 1 ピクセルあると 2 体が同じマスに入らないので、色が混ざる問題も一緒に消える（R4）

## 画面で見つけたこと（2026-10-08）

- 左を向いて道具（砂時計）を持つ本体が仲間（おばけ）の後ろに入ると、本体の体はほぼ消えるが、左手の砂時計は仲間の左側にはみ出して残り、仲間が砂時計を持っているように見えた（vhs の録画。仲間 2 体と Monitor を使う作業）。道具は持ち主の絵の外側に描くので、手前の子が持ち主と道具の間に入ると起きる
