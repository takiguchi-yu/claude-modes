# clawd-wander: サブエージェントが動いている間も本体を出す

Claude が作業していなくても、サブエージェントが動いている間は本体の Clawd を出しておく。サブエージェントだけが動いているセッションで、Clawd が消えて寂しくならないように。

**Status:** done（2026-10-07。テストで確認。画面での確認はまだ）
**Blocked by:** なし

## 要件

1 コマ = 100 ms。「仲間が動いている」は、サブエージェントの仲間が現れかけ・いるのどれかであること（消えかけは含まない）。

```text
R1  [WHILE] Claude が作業中、または仲間が動いている間、帯は本体を出す。
R2  [WHEN]  Claude が作業しておらず、仲間も動いていないとき、帯は本体を消し始める（仲間と同時にふわっと消える）。
R3  [KEEP][WHEN] 仲間が一覧から外れたとき、帯は引き続き跳ねさせてから消し、顔ぶれから外す。
R4  [KEEP][IF]   アンケートが出ている・Raster が無い・帯が狭い場合、帯は引き続き何も描かない。
```

## 変わること

- 以前は、Claude の作業が終わると、仲間が動いていても本体だけが消えた。いまは仲間が終わるまで本体も残る
- Claude が作業しておらず、仲間もいないときは、これまでどおり何も出ない（帯も詰まる）

## テストとの対応

- [x] R1・R2・R3: 既存の「サブエージェントが動いている間は…」のテストを、本体の作業が終わっても本体と仲間が残り、仲間が終わると本体も消える形に直した
- [x] R4: 既存の「Raster の無い画面では描かない」のテスト
- [x] R2: 既存の「Claude が待機中なら何も描かない」のテスト（変更なし）
