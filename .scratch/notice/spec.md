# clawd-wander: こっちを見る

Claude の作業中にユーザーが入力欄に打ち込むと、帯のマスコットが正面（ユーザーのほう）を向いて、ぴょこっと跳ねる。

**Status:** 取り下げ（2026-10-06。画面で確認したうえで、機能ごと削除した）
**Blocked by:** なし

## 要件

1 コマ = 100 ms。N = 15 コマ（1.5 秒）。跳ねる浮きは HOP = [1, 2, 2, 1] ピクセル。

```text
R1  [WHEN]  入力欄が編集されたとき（prompt.edit）、またはプロンプトが送られたとき（prompt.submit）、帯は「いる」全員に、こっちを見るのを始めさせる。
R2  [WHEN]  こっちを見るのを始めるとき、見ていなかった 1 体は残りを N コマにして跳ねる。すでに見ている 1 体は、跳ねている途中なら残りを変えず、跳ね終えていれば残りを N − 4 コマに延ばす（打ち続けても跳ね直さない）。
R3  [WHILE] こっちを見ている間、帯はその 1 体を歩かせず、正面・直立で描き、見始めてから 4 コマは HOP の浮きを付ける。
R4  [WHEN]  こっちを見るのを始めるとき、帯はその 1 体の活動の途切れを 0 に戻す（居眠りしていれば起きる）。
R5  [WHEN]  こっちを見ている残りが尽きたとき、帯はその 1 体をその場から歩かせ直す。
R6  [IF]    驚いている場合、帯は驚きを優先して描く（こっちを見る残りは減り続ける）。
R7  [KEEP][WHILE] 現れかけ・跳ねる・消えかけの間、帯は引き続き出入りの見え方で描き、こっちを見るのを始めさせない。
R8  [KEEP][WHEN]  入力欄の編集・プロンプトの送信のとき、帯は引き続き入力の中身を変えずに次へ渡す。
```

## デシジョンテーブル（このコマにどう描くか。.scratch/emotes/spec.md の T1〜T4 に「こっちを見る」を足す）

| --- | --- | --- | --- | --- | --- |
| 出入りの状態が「いる」 | F | T | T | T | T |
| 驚いている | - | T | F | F | F |
| こっちを見ている | - | - | T | F | F |
| 活動の途切れが 600 コマ以上 | - | - | - | T | F |
| 出入りの見え方 | X | | | | |
| 「!」 | | X | | | |
| 正面・直立・HOP の浮き | | | X | | |
| 寝姿と z | | | | X | |
| 歩く（道具を含む） | | | | | X |

覆う組み合わせ: T1 = 8、T2 = 4、T5 = 2、T3 = 1、T4 = 1、計 16 = 2⁴。重なりなし。
こっちを見始めると途切れは 0 になる（R4）ので、T5 と居眠りは実際には重ならない。

## 契約

```text
契約: notice(crew)
- 事後: 「いる」者は R2 のとおりの残り、途切れ 0。それ以外の者は変わらない
- 不変: crew を変更しない

契約: Member.notice（追加）
- 値: こっちを見る残りコマ数。0 なら見ていない
```

## テストとの対応

- [x] R1・R2・契約 notice: いる者だけが見始め、残りは N。跳ねている途中は変わらず、跳ね終えていれば N − 4 に延びる
- [x] R3・T5: 見ている間は歩かず、正面・直立、最初の 4 コマは HOP の浮き
- [x] R4: 居眠りしていても起きて見る
- [x] R5: 残りが尽きると、また歩く
- [x] R6・T2: 驚いている間は「!」を描く
- [x] R7・T1: 出入りの途中は見始めない
- [x] R1・R8・register: 実際の prompt.submit で本体が見始め、送ったプロンプトはそのまま通る
