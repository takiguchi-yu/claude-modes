# clawd-wander: マスコットが現れるときもふわっとさせる

消えるとき（浮き上がりながらドットが抜ける）の逆再生で、現れるときは上から降りながらドットが埋まるようにする。
本体の Clawd（作業の開始）とサブエージェントの仲間（顔ぶれに加わったとき）の両方が対象。

**Status:** done（2026-10-06。2026-10-08 に vhs の録画で、本体・仲間とも、上から降りながらドットが埋まって現れ、浮き上がりながらドットが抜けて消えることを確認）
**Blocked by:** なし

## 現状

- 本体もサブエージェントも、出すと決めたコマでいきなり全部のドットが出る
- 消えかけのうちに出し直すと、一瞬で元の濃さに戻る

## 要件

F = 12 コマ（10 コマ = 1 秒なので約 1.2 秒）。濃さ＝ドットを残す割合（0〜1）。浮き = 何ピクセル上にずらすか。

```text
R1  [WHEN]  本体の作業が始まったとき、帯は本体の Clawd を、濃さ 0・浮き 4 から F コマかけて濃さ 1・浮き 0 まで降ろしながら現す。
R2  [WHEN]  サブエージェントが顔ぶれに加わったとき、帯はその仲間を R1 と同じ現れ方で現す。
R3  [WHILE] 現れかけの間、帯はその 1 体を正面向き・直立のまま止めておき、歩かせない。
R4  [WHEN]  現れかけになって F コマ経ったとき、帯はその 1 体を「いる」にし、次のコマから歩かせる。
R5  [WHEN]  現れかけの 1 体が引っ込められたとき、帯はその時点の濃さのまま消え始める（濃さが飛ばない）。
R6  [WHEN]  消えかけの 1 体がまた出されたとき、帯はその時点の濃さのまま現れ直す（濃さが飛ばない）。
R7  [WHILE] 現れかけの 1 体がいる間、帯は描くものがあるとみなして表示を続ける。
R8  [KEEP][WHEN]   「いる」1 体が引っ込められたとき、帯は引き続き F コマかけて浮き上がりながら消す。
R9  [KEEP][WHILE]  「いる」間、帯は引き続きその 1 体を歩き回らせる（歩き方・速さは変えない）。
R10 [KEEP][WHEN]   サブエージェントの仲間が消えきったとき、帯は引き続きそれを顔ぶれから外す。本体は外さない。
R11 [KEEP][WHEN]   仲間が顔ぶれに加わるとき、帯は引き続き、まだいない種類と色を割り当て、ランダムな位置に置く。
R12 [KEEP][WHILE]  描くもの（現れかけ・いる・消えかけ）が 1 体もいない間、帯は引き続き何も描かない。
R13 [KEEP][IF]     顔ぶれが空の場合、帯は引き続き本体を「いない」状態で補ってから処理する。
```

## 状態遷移表

1 体ごとの状態。「出す」は本体なら作業中になったとき、仲間なら一覧に載っている・起動したとき。
「引っ込める」は本体なら作業が終わったとき、仲間なら一覧から外れたとき。

| 現在 \ イベント | 出す | 引っ込める | 1 コマ進む |
| --- | --- | --- | --- |
| いない | S1 → 現れかけ（残り F） | S2 → いない（何もしない） | S3 → いない（何もしない） |
| 現れかけ（残り a） | S4 → 現れかけ（何もしない） | S5 → 消えかけ（残り F − a） | S6 → a = 1 ならいる、それ以外は現れかけ（残り a − 1） |
| いる | S7 → いる（何もしない） | S8 → 消えかけ（残り F） | S9 → いる（1 歩進む） |
| 消えかけ（残り l） | S10 → 現れかけ（残り F − l） | S11 → 消えかけ（何もしない） | S12 → l = 1 ならいない（仲間は顔ぶれから外す）、それ以外は消えかけ（残り l − 1） |

- 濃さ: 現れかけ（残り a）は 1 − a/F、消えかけ（残り l）は l/F。S5・S10 で残りを F から引くのは、濃さを変えずに向きだけ反転させるため
- 浮き: 現れかけは ⌈a/3⌉、消えかけは ⌊(F − l)/3⌋（どちらも最大 4）
- 仲間は S12 で外すので、「いない」状態になるのは本体だけ

## 契約

```text
契約: actors(crew)
- 事前: crew の先頭は本体（MAIN）
- 事後: 「いない」者は含まない。
        現れかけ・消えかけの者は facing = 'front'、pose = 'stand'、0 ≤ opacity ≤ 1、0 ≤ lift ≤ 4。
        「いる」者は opacity と lift を持たない
- 不変: crew を変更しない

契約: Member.presence（Member.fade を置き換える）
- 値: { kind: 'gone' } | { kind: 'here' } | { kind: 'arriving', left: 1〜F } | { kind: 'leaving', left: 1〜F }
- 不変: 仲間（MAIN 以外）が 'gone' のまま顔ぶれに残ることはない
```

事前条件（先頭が本体）を破られたとき（空の顔ぶれ）の振る舞いは R13。
