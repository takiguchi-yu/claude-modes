# clawd-wander: もっとうろうろさせる

いまの動きは「端まで 12〜60 ピクセル歩く → 8〜30 コマ休む」の繰り返しで、散歩に近い。
その辺を行ったり来たりする「うろうろ」に寄せる。短い往復を中心にし、振り返り・立ち止まり・速さの変化を足す。

**Status:** done（2026-10-06。全機能の動作確認で、距離・速さ・居眠り 60 秒を画面で確認済み）
**Blocked by:** なし

## 現状

- 歩く距離は 12〜60 ピクセルで、歩き終えると必ず 8〜30 コマ休む
- 速さは常に 1 コマ 1 ピクセル
- 脚は経過コマで入れ替わる（歩いていれば速さに関係なく 2 コマごと）

## 要件

1 コマ = 100 ms。対象は `hooks/wander.ts` の `step` と `poseOf`。

```text
R1  [WHEN]   歩き始めるとき、wander は歩く距離を、50% の確率で 8〜24 ピクセル、50% の確率で 40〜160 ピクセルから選ぶ（2026-10-06 に 3〜14／20〜50 → 75%: 8〜24／25%: 30〜80 → 現在の値へ延長）。
R2  [WHEN]   歩き始めるとき、wander は速さを、ゆっくり（1 コマで 1 ピクセル）15%・ふつう（1 コマで 2 ピクセル）60%・小走り（1 コマで 3 ピクセル）25% から選ぶ（2026-10-06 に割合を 35%・55%・10% から、速さを 2 コマで 1・1・2 ピクセルから変更）。
R3  [WHEN]   選んだ距離を歩き終えたとき、wander は 45% の確率で振り返ってすぐ歩き出し、35% で 2〜6 コマ立ち止まり、20% で 10〜30 コマ休む。
R4  [WHEN]   立ち止まり・休みが終わったとき、wander は端にいれば内側を向き、それ以外は左右を半々で選んで歩き出す。
R5  [WHILE]  休んでいる間、wander は 1 コマごとに 13% の確率で左・右・正面のいずれかを向く。
R6  [WHILE]  立ち止まっている間、wander は向きも位置も変えない。
R7  [WHILE]  歩いている間、wander は位置が 2 ピクセル変わるごとに脚のコマを入れ替え、立ち止まり・休みの間は直立にする。
R8  [ALWAYS] wander が向きを変えるまでに歩く距離は、幅 600 ピクセルの帯で平均 55〜100 ピクセルになる（2026-10-06 に「20 ピクセル以下」→「25〜50」→ 現在の値へ変更）。
R9  [KEEP][WHEN]   歩いて次の位置が端を越えるとき、wander は引き続き位置を変えずに向きを反転する。
R13 [WHEN]   歩いて次の位置が端を越えるとき、wander は残り距離を 1 減らす（帯が絵の幅しかなくても、反転し続けて止まらないことが無いように）。
R10 [KEEP][ALWAYS] wander は引き続き x を 0 以上 maxX 以下に保ち、帯が縮んだら最初にその中へ収める。
R11 [KEEP][IF]     maxX が負の場合、wander は引き続き maxX を 0 とみなす。
R12 [KEEP][WHILE]  現れかけ・消えかけの間、帯は引き続きその 1 体を歩かせない（crew.ts 側。.scratch/fade-in/spec.md R3）。
```

## 状態遷移表

| 現在 \ 出来事 | 1 コマ進む（残りがある） | 残りが尽きる | 次の位置が端を越える |
| --- | --- | --- | --- |
| 歩く（残り距離・速さ） | S1 → 歩く（速さどおりに 1〜3 ピクセル進み、残り距離を減らす） | S2 → R3 の確率で、歩く（振り返り）／立ち止まる／休む | S3 → 位置はそのまま向きを反転し、残り距離を 1 減らす。尽きたら S2 と同じ |
| 立ち止まる（残りコマ） | S4 → 立ち止まる（何も変えない） | S5 → 歩く（R4 の向き、R1・R2 の距離と速さ） | S6 → 起こりえない（動かないので端を越えない） |
| 休む（残りコマ） | S7 → 休む（R5 のとおり向きだけ変わる） | S8 → 歩く（S5 と同じ） | S9 → 起こりえない（同上） |

## 契約

```text
契約: step(w, maxX, random)
- 事前: random は 0 以上 1 未満を返す。maxX は数値
- 事後: 0 ≤ x ≤ max(0, maxX)。x は帯に収めた元の位置から 3 ピクセル以内。
        mode は 'walk' | 'pause' | 'rest'。left は 1 以上
- 不変: w を変更しない

契約: Wanderer（mode に 'pause'、gait を追加）
- mode = 'walk' のとき left は残り距離（ピクセル）、gait は 'stroll' | 'walk' | 'dash'
- mode = 'pause' | 'rest' のとき left は残りコマ数
```

事前条件 maxX を破られた（負の）ときは R11。

- 申し送り: 確率と距離（R1〜R3）は見た目の好みで決めた値。画面で見て、うろうろ感が強すぎる・弱すぎるなら `setOff` と `arrive` の数値を調整する
- 2026-10-06 変更: 「もっとうろうろさせて」を受け、帯の広い範囲を歩くように R1（遠出 50%・40〜160 ピクセル）・R2（ゆっくりを減らし小走りを増やす）・R8 を変更。期待値は 1 回 58 ピクセル、同じ向きに続けて歩く確率 27.5%（立ち止まり・休み 55% × 向き半々）で、向きを変えるまで約 80 ピクセル。あわせて居眠りまでの時間を 60 秒に延ばした（.scratch/emotes/spec.md R5）
- 2026-10-06 変更: 動作確認で「ベースのスピードはもっと上げて良い」との指摘。3 段とも 1 段ずつ上げ、ゆっくり 1・ふつう 2・小走り 3 ピクセル／コマにした（ふつうは 2 倍）。1 コマの移動の上限は 3 ピクセルになる。ゆっくりも毎コマ進むので、足を止める拍は無くなった
- 2026-10-06 変更: 動作確認で「まだ遅い」との指摘。1 コマ 100 ms のまま歩幅を 2 倍にし、ゆっくり 2・ふつう 4・小走り 6 ピクセル／コマ（ふつうは 20 マス／秒）。歩幅が大きくなったので、脚は 1 コマごとに入れ替え（R7）、端では端まで進んでから反転する（R9・R13）。コマを 50 ms に縮めれば同じ速さでもなめらかになるが、出入り・驚き・居眠り・道具のコマ数をすべて倍にする必要があるため見送った
- 2026-10-06 変更: 4 ピクセル／コマ（と、それに合わせた脚の毎コマ入れ替え・端まで進む折り返し）は動作確認で「一つ前の速度に戻して」となり、ゆっくり 1・ふつう 2・小走り 3 ピクセル／コマに戻した。脚と端の扱いも、4 ピクセル歩幅のために入れたものなので元に戻した
