# clawd-wander: 行列の途中で仲間が止まっても、並び順を崩さない

行列の途中で仲間が驚く・居眠りする・消えかけから戻ると、後ろの仲間がその仲間を追い越して入れ替わり、戻るときに振り返る。道具を持っていると、振り返った間は道具が後ろの仲間に向いて重なる。

**Status:** done（2026-10-07 起票・同日対応。ユーザーが「後ろの仲間も待つ」を選んだ。レビューの指摘で R5・R6、2 回目のレビューの指摘とユーザーの判断で R7・R8 を追加。テストで確認。同日、画面で驚き・居眠りの後ろで待つのを確認）
**Blocked by:** なし

## 見つけたときの状況

道具を持つ仲間の行列の間隔を直したあとのレビュー（2026-10-07、.scratch/parade/spec.md の R4・R10）で見つかった。変更前からある振る舞い（parade の R7）。

- 再現: 2 体（a はハンマー、b は虫めがね）が並び終えた行列で a を驚かせる（テストの `advanceBy(lineUp(wield(wield(withFriends(), 'a', 'Edit'), 'b', 'Read'), seq(0, 0.9999), 400), 60, 400)` に `poke(crew, 'a', true)`）。驚いている 2 秒の間に、b は 1 番目の目標へ進んで a を追い越す。驚き終えると a が 1 番目に戻るので、b は後ろへ下がるために振り返り、虫めがねが 4 コマ（驚かせてから 19〜22 コマ目）後ろを向く。入れ替わる間、a と b の体も重なる
- 居眠りからの起床、消えかけから戻った仲間でも、同じ形で起きる。レビューの乱数シミュレーションでは、振り返った子の道具が誰かに 1 ピクセル以内まで近づいた割合は、驚きで 2,245/2,862 件、居眠りで 200/331 件
- 原因: `march` は、歩ける仲間だけで並びと間隔を決め直す（`spacing(main, walkers)`）。歩けない仲間の分だけ列が詰まり、戻ると広がる
- そのチケットで直さなかった理由: 道具が前の子に重なる指摘とは別の、並び順の決め方の問題。直すには、歩けない仲間の扱いを決める必要がある

## 要件

1 コマ = 100 ms。「歩けない」は parade の定義どおり、出入りの状態が「いる」でない（現れかけ・跳ねる・消えかけ）か、驚いている・居眠りしていること。「並び順」は行列を始めたときに決めた順（parade の R9）。

```text
R1 [WHILE] 行列の間、並び順で前に歩けない仲間がいる間、帯はその後ろの仲間を前へ進ませず、その場で直立させ、行列の向きを向かせる。2026-10-07 に「向きは変えない」から変更（回り込みの途中の子が後ろ向きのまま立ち続け、道具が後ろの子に重なったため）。
R2 [WHEN]  並び順で前の歩けない仲間が全員、歩けるようになるか消えきって顔ぶれから外れたとき、帯は後ろの仲間を目標へ進ませる（parade の R4・R5・R10）。
R3 [KEEP][WHILE] 行列の間、帯は引き続き歩けない仲間を目標へ進ませず、ふだんどおりの見え方で描く（parade の R7）。
R4 [KEEP][WHILE] 行列の間、並び順で前に歩けない仲間がいない仲間は、帯は引き続き目標へ進ませる（本体が止まっている間も、並び順で後ろの仲間が止まっている間も）。
R5 [WHILE] R1 で待っている間に、すぐ前の仲間との間が、道具の分を含めた 1 体分の間隔（parade の R4 の max(前の幅, 自分の幅) + 2 + P、R7 の分を含む）より狭くなったとき、帯はその仲間をその分だけ下がらせる（1 コマ 4 ピクセルまで。帯からは出さない）。すぐ前の仲間より後ろにいれば向きを変えずに下がり（後ずさり）、前にいれば（回り込みの途中など）進む向きを向いて下がる。
R6 [WHEN]  行列を始めるとき、帯は歩けない仲間を並び順の最後に回す。歩ける仲間どうし、歩けない仲間どうしは、それぞれ parade の R9 のとおりに並べる。
R7 [WHILE] 左へ進む行列で、すぐ前の仲間が驚きの「!」か居眠りの zZ を出している間、帯は R5 の間隔に、その記号が絵の右端から張り出す分を足す（記号は絵の右横、つまり後ろの仲間の側に描くため。.scratch/emotes/spec.md の R4・R5）。
R8 [WHEN]  行列の間に新しい仲間が来たとき、帯はその仲間を、並び順の最後尾に続く歩けない仲間より前に入れる（最後尾で止まっている仲間の後ろで待たせない）。
```

## 変わること

- 以前は、歩けない仲間を外して並び直していた。後ろの仲間はその仲間を追い越して前の席に入り、戻るときに振り返って下がっていた
- いまは後ろの仲間がその場で待つ。追い越さないので入れ替わらず、歩けるようになったら全員が前へ追いつく（振り返らない）
- 待っている間に道具を持つと、すぐ前の仲間に道具が重ならないよう下がる（R5。待つ間は一切動かない形だと、道具が前の仲間に重なったままになるとレビューで分かったため）
- 行列を始めるときに歩けない仲間（居眠り・驚き・出入りの途中）は、並び順の最後に回す（R6。前に置くと、後ろの仲間が始めから止まり、本体より前にいた仲間は本体の通り道で固まって本体と重なるとレビューで分かったため）
- 限界: 行列の途中で前の仲間が居眠りを続けると、その後ろの仲間は行列が終わるまで立ち止まったままになる（ユーザーが受け入れた）。行列を始めたときに並び順の最後に回った歩けない仲間の体と、ほかの仲間の体は、歩いてすれ違うときに重なりうる（変更前と同じ）
- 待って立つ間は行列の向きを向く（R1）。回り込みの途中で前の仲間が止まった子は、進む向きを向いて後ろへ回り、立ち止まったら行列の向きを向く（R5）。左へ進む行列では、驚き・居眠りの記号の分も空けて待つ（R7）。行列の途中で来た仲間は、最後尾で止まっている仲間より前に並ぶ（R8）
- 限界: 本体が驚いた・居眠りした場合の記号は、R7 の対象外（1 番目の仲間は待っておらず、行列の間隔どおりに並ぶため）。左へ進む行列で本体が驚くと、「!」が 1 番目の仲間の道具に接することがある
- 限界（2 回目のレビューで分かった、まれなもの）: 帯の端で下がりきれないと、道具がすぐ前の仲間に重なったまま待つ。R5 はすぐ前の仲間しか見ないので、すぐ後ろが歩けない仲間だと、下がった分だけその仲間に食い込む。最後に回った歩けない仲間が、ほかの仲間に追い越されきる前に歩けるようになると、後ろ向きで列を通り抜けて最後尾へ下がる。行列を始めるかどうかは 1 コマ前の状態で決めるので、居眠りに入る直前の仲間は歩ける側に並び、後ろの仲間が始めから待つことがある
