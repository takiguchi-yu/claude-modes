# clawd-wander: 小踊り（バンザイ）

ひとり遊び（.scratch/play/spec.md）の 1 つ。本体の Clawd がその場で立ち止まり、腕を上げ下げして小さく踊る。

**Status:** 取り下げ（2026-10-08。画面で確かめたうえで、ユーザーの希望で機能ごと削除した）
**Blocked by:** なし

## 要件

1 コマ = 100 ms。

```text
R1  [WHEN]  小踊りを始めるとき、帯は本体をその場で止める（歩かせない）。
R2  [WHILE] 小踊りの間、帯は 4 拍（1 拍 = 6 コマ。計 24 コマ = 2.4 秒）踊らせる。各拍の前半 3 コマはバンザイ（両手を上げる絵）、後半 3 コマは正面を向いて直立する。
            バンザイの向きは拍ごとに左・右・左・右と変える（目の位置で向きが分かる）。
R3  [WHILE] バンザイの絵は、Clawd の両腕（胴の 3 行目の左右に 2 ピクセルずつ張り出した部分）を消し、手を絵の最上行（空き行）の左右の端と、
            その下の行（胴の 1 行目）の胴の左右のすぐ外に置く（斜めに上げた腕）。
R4  [WHILE] 小踊りの間、帯は道具を描かない（使っている呼び出しの数と残りは props の仕様のとおりに変わり続ける）。
R5  [WHEN]  4 拍を踊り終えたとき、帯は小踊りを終える（終わったあとは .scratch/play/spec.md の R6）。
R6  [WHEN]  小踊りの間に仲間が加わったとき、帯はその場で小踊りをやめる。
```

## 契約

```text
契約: Dance（dance.ts）
- 値: { left: number }（残りコマ。1〜DANCE_FRAMES）

契約: dancePose(left)（dance.ts）
- 事後: そのコマの { pose: 'banzai' | 'stand', facing: 'left' | 'right' | 'front' }

契約: Pose に 'banzai' を足す（mascots.ts）
- Clawd は R3 の絵。ほかのマスコットは直立（stand）と同じ絵
```

## テストとの対応

- [x] R1・R2・R5: 24 コマの間その場で踊り、拍ごとにバンザイ（左・右・左・右）と直立をくり返し、終わると立ち止まる
- [x] R3: バンザイの絵は腕が上にあり、胴の 3 行目の張り出しが無い
- [x] R4: 小踊りの間は道具を描かない
- [x] R6: 仲間が加わるとやめる
