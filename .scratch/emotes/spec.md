# clawd-wander: 完了ジャンプ・びっくり・居眠り

マスコットが Claude Code の様子に反応する。作業が終わると跳ねてから消え、ツールが失敗すると驚き、
ツールの呼び出しが長く途切れると居眠りする。帯は 3 行のまま、記号（! と z）はマスコットの右横に描く。

**Status:** done（2026-10-06。2026-10-08 に vhs の録画で、作業の終わりに跳ねてから消えること・居眠りの寝姿と zZ を確認。跳ねる高さで高さ 6 ピクセルの仲間の頭が切れることも確認〈申し送り〉）。2026-10-08 に R11〜R13（呼び出しが動いている間は眠らない）を追加
**Blocked by:** なし

## 要件

1 コマ = 100 ms。「活動」は、その 1 体のループでツールの呼び出しが始まる・終わること
（本体は `agentId` の無い `tool.call`、仲間はその `agentId` の `tool.call`）。

```text
R1  [WHEN]  「いる」1 体が引っ込められたとき、帯はその 1 体を 4 コマかけて 1・2・2・1 ピクセル跳ねさせ、それから消え始める。
R2  [WHILE] 跳ねている間に出し直されたとき、帯はその 1 体を「いる」に戻す。
R3  [WHEN]  ツールの呼び出しが失敗した（拒否された・エラーを返した）とき、帯はその呼び出し元の 1 体を 20 コマ（2 秒）驚かせる。2026-10-06 に 8 コマから延長（一瞬過ぎたため）。
R4  [WHILE] 驚いている間、帯はその 1 体を歩かせず、絵の右端の塗りから 1 ピクセル空けて、ドット絵の「!」（高さ 6 ピクセルの縦棒と点）を赤（0xe04f4f）で描く（2026-10-07 に持ち主の色から赤に変更。ユーザーの希望）。最初の 8 コマは 1 コマごとに左右へ 1 ピクセル震わせ、残りは止まって「!」だけを出す。
R5  [WHILE] 「いる」1 体の活動が 600 コマ（60 秒。2026-10-06 に 20 秒から延長）途切れている間、帯はその 1 体を歩かせず、種類ごとに描いた小さな寝姿（高さ 4 ピクセル・幅は元の 8 割以下・目を閉じる・足元と左右の中央は元の絵にそろえる）にし、寝姿の右横にフォントの文字「z」と、その右上に「Z」を描き、5 コマごとに 1 行上下させる（zZ が浮かぶ形）。2026-10-06 に「目を閉じる・3×3 の z」→「1 ピクセル沈む座り姿・4×4 の Z」→ 小さな寝姿、記号はドット絵からフォントの文字へ変更（居眠りに見えない、小さくしたいという画面での指摘による）。2026-10-08 に、600 コマを /config の doze_seconds で変えられるようにした（既定 60 秒。.scratch/config/spec.md）。
R6  [WHEN]  活動があったとき、帯はその 1 体の途切れを 0 に戻す（居眠りから起きる）。
R7  [WHEN]  居眠り中の 1 体のツールが失敗したとき、帯は居眠りより驚きを優先して描く。
R8  [KEEP][WHILE] 現れかけ・消えかけの間、帯は引き続きその 1 体を歩かせず、驚き・居眠りも描かない。
R9  [KEEP][WHILE] 驚いても居眠りもしていない「いる」1 体を、帯は引き続き歩かせる（.scratch/wander/spec.md）。
R10 [KEEP][WHEN]  活動が無い呼び出し元（顔ぶれにいない agentId）のツールが失敗したとき、帯は引き続き誰も驚かせない。
R11 [WHILE] 「いる」1 体のツールの呼び出し（どのツールでも）が 1 つ以上動いている間、帯はその 1 体の活動の途切れを数えない（0 のまま。居眠りしない）。2026-10-08 に追加（60 秒を超えるテストや前面の Agent の間に、道具を持ったまま眠って道具が消えていたため）。
R12 [WHEN]  ツールの呼び出しが始まるとき、帯は呼び出し元の 1 体の動いている呼び出しの数を 1 増やす。終わるとき（成功・失敗・拒否・中断・例外のどれでも、1 つの呼び出しで 1 回だけ）、1 減らす（0 より下げない）。消えきっている 1 体・顔ぶれにいない id では数えない。
R13 [WHEN]  1 体が消えきったとき、帯はその 1 体の動いている呼び出しの数を 0 にする。
```

動いている呼び出しの数は、道具の「使っている呼び出しの数」（.scratch/props/spec.md）と別に数える。道具の数は道具の対応表のツールだけを数えるので、テストでない長い Bash（ビルドなど）の間も眠らないようにするため。
終わりも中断も届かない呼び出しがあると、その 1 体は消えきるまで眠らない。権限の確認や AskUserQuestion でユーザーの返事を待つ間も、呼び出しは動いているので眠らない。

## 状態遷移表（.scratch/fade-in/spec.md の S8 を変える）

「跳ねる」を「いる」と「消えかけ」の間に足す。ほかの行・列は fade-in の表のまま。

| 現在 \ イベント | 出す | 引っ込める | 1 コマ進む |
| --- | --- | --- | --- |
| いる | S7 → いる | S8' → 跳ねる（残り 4）※従来は消えかけ（残り F） | S9 → いる |
| 跳ねる（残り j） | S13 → いる | S14 → 跳ねる（何もしない） | S15 → j = 1 なら消えかけ（残り F）、それ以外は跳ねる（残り j − 1） |

- 跳ねる間の見え方: 濃さ 1、浮きは残り 4・3・2・1 のとき 1・2・2・1
- 跳ねる間は歩かない。仲間の起動の知らせ（join）では「いる・現れかけ」と同じく出しているものとして扱わない

## 契約

```text
契約: poke(crew, id, failed)
- 事前: id は本体（MAIN）か仲間の id
- 事後: id の 1 体の途切れが 0。failed なら驚きの残りが 20（その 1 体が「いる」とき）
- 不変: crew を変更しない。id がいなければ同じ顔ぶれを返す（R10）

契約: Actor.emote（追加）
- 値: undefined | { kind: 'startle' } | { kind: 'doze'; high: boolean }
- 事後: emote があるとき、記号はそのコマの絵の右端の塗りから 1 ピクセル以上空けて、帯からはみ出さない範囲で描く。「!」はドット絵、z・Z はフォントの文字
```
